Jam订阅包含哪些内容

订阅内容取决于所选套餐。以下是所有功能的完整列表：

《买家画像》分析报告

该报告可以帮助您研究目标受众，更深入地了解那些下单量高于平均水平的买家。这些信息将在以下方面助力业务增长：优化商品品类、完善商品信息、调整品牌定位、选择推广渠道、提升销售表现。报告中可查看的信息包括：年龄、性别、地区、兴趣、平均客单价、活跃时间段及下单频率。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/bbd0a823-3842-46ae-bae5-e909bb4c1bc0.png.webp)

[关于《买家画像》报告的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/report-buyer-portrait-china)

《热门搜索词》分析报告

统计那些带来最多商品点击、加购和下单的搜索关键词。具体可分析的搜索词数量取决于订阅套餐：“标准版”最多支持30个，“高级版”支持100个。该报告可通过API下载。

从报告中您可以了解：

- 影响商品在搜索结果中排序的参数；
- 商品在搜索中被买家看到的概率；
- 搜索带来的点击、加购、下单及转化率；
- 各地区的订单占比及平均配送时间。

此报告有助于您进行商品的SEO优化和精准投放广告。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/a907da6d-f2a3-46fa-b2ae-ec23df31ded5.png.webp)

[关于《热门搜索词》报告的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/report-search-queries-china)

扩展报告《销售漏斗》

除了所有用户都可使用的基础功能外，订阅“Jam”后可额外获得与其他卖家销售漏斗的对比分析功能，以及季节性分析功能。

事件日历将显示您的商品发生的所有变化（如价格调整、图片更新等），并分析这些变化对销售漏斗各阶段和其他业务指标的影响。

[关于《销售漏斗》报告的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/sales-funnel-report-china)

《市场分析》报告

帮助您识别热销但稀缺的商品，以扩大您的产品范围。

[关于市场分析的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/report-niche-analysis-ch)

商品对比

此报告允许您选择任意两个Wildberries商品，比较它们在销售漏斗各阶段的表现、搜索排名及其他关键指标。

有助于制定店铺运营策略，以及SEO关键词、定价、定位及商品推广等策略的优化。

[关于商品对比的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/report-comparison-of-cards-china)

评论置顶

允许您将一条评论置顶展示在商品详情页，仅限评分达到4.5及以上的卖家使用。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/64dac5b5-fb1d-4232-9ae1-346b6d85be3c.png.webp)

[关于评论置顶的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/pinned-reviews-china)

高级 API

支持更快速的店铺管理和报告下载，可获取《销售漏斗》和《热门搜索词》中过去365天的数据。

商品详情页与目录中的视频自动播放

该功能会在商品详情页、商品目录页和搜索结果中自动播放视频。用户进入商品页面时，视频将立即播放。启用该功能后，商品更容易吸引用户注意。

[关于视频自动播放的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/video-autoplay-in-product-card-and-catalog-china)

图片标记

如果商品详情页图片中出现了您店铺的其他商品，可以添加标签。用户点击标签后，即可跳转至相应商品页面。

[关于图片标记的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/product-tags-on-photos-in-the-product-card-china)

主图A/B测试

上传2个版本的主图，测试哪一个能带来更多浏览和订单。

[关于A/B测试的更多信息](https://seller.wildberries.ru/instructions/ch/ch/material/a-b-testing-of-the-main-photo-china)

虚拟试衣照相馆

上传商品图片后，WB神经网络可将衣物“穿”在模型身上，并自动添加背景。也可以上传模特实拍图，并使用该功能 替换照片中的模特和背景。生成的图像可以添加到商品详情页中。

[关于虚拟试衣照相馆的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/photostudio-product-photo-generation-using-ai-china)

图片编辑器

一个用于编辑商品图片的工具。订阅任意Jam套餐后，即可不限量使用“拼图”编辑功能。

[关于图片编辑器的更多信息](https://seller.wildberries.ru/instructions/ch/ch/material/photo-editor-china)

商品描述生成

WB神经网络可基于关键词，结合您选择的文本长度与语气风格，自动生成高转化率的商品描述。

富媒体内容生成

WB神经网络可根据商品详情页中的文本与图片，在商品描述中的生成促销页面。

“卖家推荐”模块

可在商品页面中设置“卖家推荐”板块，推荐同类主题商品或店铺中同品类的其他商品。

该功能仅适用于“高级版”套餐。

[关于卖家推荐的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/seller-recommends-block-in-the-product-card-china)

替代商品编号服务

该功能可用于检测您的推广渠道和传播方式的有效性。通过替代商品编号，您可以追踪每个推广渠道的转化效果——包括多少用户通过指定渠道进入了商品页面、加入购物车并最终下单。此外，您还可以获取购物车转化率和下单转化率的数据。

这一功能有助于您对流量来源进行分类分析，查看各渠道的推广数据，评估具体渠道的营销效果。

[关于替代商品编号服务的更多内容](https://seller.wildberries.ru/instructions/ch/ch/material/replacement-articles-cn)
