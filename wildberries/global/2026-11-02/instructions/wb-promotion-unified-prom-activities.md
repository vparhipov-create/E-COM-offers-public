WB推广：付费模式与运作原理

Wildberries 上有数百万种商品，而买家最常选择的往往是那些出现在搜索结果首页的商品。WB 推广可以帮助您提升商品详情页在展示区域中的位置，使其对买家更加显眼。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/b2a47cc1-c649-44e3-8846-578b040fc971.webp)

## WB 推广的工作原理

要在 Wildberries 上推广商品：

1. [在 WB 推广账户中](https://cmp.wildberries.ru/campaigns/create) 创建一个活动。
2. 选择活动的付费模式：按展示付费或按点击付费。对于按展示付费的推广，设置手动出价或统一出价。
3. 确定活动预算——您愿意为推广花费的金额。
4. 对于手动出价活动，选择您要推广商品的展示区域。
5. 将您希望推广的商品添加到活动中。
6. 设置出价——每件商品的推广费用。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/168cca06-83d2-4918-8376-223b2e798311.png.webp)

另请阅读关于 [启动活动](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-start-promotion-on-wildberries?categoryId=0194fe5f-7428-78cb-a97b-7e258be9abdf&goBackOption=prevRoute) 的指南。

## 商品详情页展示区域

Wildberries 上的商品在以下 3 个展示区域中显示：

- 搜索,
- 目录,
- 推荐。

WB 推广有助于提升商品详情页在这些区域中的位置。

在搜索结果中，买家看到的商品是其描述与查询内容相匹配的商品。搜索是最关键、转化率最高的展示区域。当商品的特性及描述与买家输入的查询匹配时，商品会进入搜索结果。Wildberries 的算法会分析查询内容及商品详情页的描述，从而确定哪些商品会显示在搜索结果中。因此，我们建议您在商品详情页中详细、准确地填写商品描述。

![](https://static-basket-02.wbbasket.ru/vol20/article-static/873f70a2-b3e4-4d1a-a813-72795e317fba.webp)

关于商品详情页的填写，更多内容请阅读 [指南。](https://seller.wildberries.ru/instructions/ch/ch/material/card-creation-rules-china?categoryId=about-item-card&goBackOption=prevRoute)

## 推广付费模式

WB 推广提供两种活动付费模式：

- 按 1,000 次展示付费 — CPM ，
- 按 1 次点击付费 — CPC  。

按展示付费（CPM）——您为推广的商品详情页展示付费。仅在商品详情页在买家屏幕上可见超过 50% 时，才按实际展示扣费。

对于 CPM 模式，出价是指 1,000 次展示的费用。

例如，如果您选择 400 卢布每 1,000 次展示的出价，实际展示为 3,000 次，那么扣费金额为：（400 卢布 × 3,000 次展示）÷ 1,000 次展示 = 1,200 卢布（每次展示 0.4 卢布）。

按点击付费（CPC）——您为买家对商品详情页的每次点击付费。在此模式下，出价是您愿意为单次点击支付的金额。

在WB推广中，点击不仅指进入商品详情页。已登录用户进行以下操作时，也计入点击：

- 点击了“快速预览”按钮；
- 从搜索结果页将商品加入购物车；
- 从搜索结果页将商品加入收藏夹。

![](https://static-basket-02.wbbasket.ru/vol20/article-static/ae79845b-a7ea-4c01-9e6f-1e09fa2cb594.jpg.webp)

按点击付费（CPC）活动同时在搜索和目录中运行。

请注意，在一个按点击付费模式投放的推广活动中，只能添加同一类目的商品。如果您想推广不同类目的商品，则需为每个类目单独创建活动。

费用按点击扣费。

如果买家在商品详情页内进行点击（如选择尺码或添加商品至购物车），不会扣费。但若买家在搜索结果页内多次点击（例如先将商品添加至收藏夹，再立即添加至购物车），则每次点击将分别扣费。

## 统一出价与手动出价推广

对于按展示付费（CPM）模式，可以启动统一出价或手动出价活动。

### 统一出价

统一出价活动可用最少的设置启动商品推广。Wildberries 算法会根据商品描述自动匹配合适的查询，并在买家搜索的展示区域中展示商品详情页。此类活动允许排除搜索查询。

更多关于按搜索查询设置活动的信息， [请参阅指南](https://seller.wildberries.ru/instructions/ch/ch/material/search-clusters-china)。

统一出价是基础工具，建议作为 WB 推广账户的入门选择。活动将在所有展示区域（搜索、目录、推荐）中以统一出价推广商品。

### 手动出价

手动出价活动提供更多管理选项。您可以选择展示区域并为每个区域设置出价，还可以排除或固定搜索查询。适合熟悉推广、已积累所在细分市场推广特点的数据，并希望利用这些知识更精确地设置活动的卖家。

在手动出价活动中，您可以在以下区域推广商品：

- 搜索和目录  ,
- 推荐  。

您可以选择其中一个选项或同时选择两者。

如果选择“搜索”展示区域，商品也将同时在目录中推广。无法单独启动搜索推广而不包括目录。

## 选择哪种支付模式

我们来比较一下 WB 推广账户中活动的工作方式。

|  | 按展示付费（CPM） | 按展示付费（CPM） | 按点击付费（CPC） |
| --- | --- | --- | --- |
|  | 统一出价 | 手动出价 |  |
| 展示区域 | 搜索、目录、推荐 | 搜索和目录、推荐 | 搜索和目录 |
| 选择展示区域 | 否 | 是 | 否 |
| 出价（就是金额） | 每 1,000 次展示 | 每 1,000 次展示 | 每次点击 |
| 为每个展示区域选择出价 | 否 | 是 | 否 |

选择 CPM 统一出价模式，如果：

- 您希望在全部展示区域推广商品，
- 您刚开始使用 WB 推广账户。

选择 CPM 手动出价模式，如果：

- 您已经了解在您的细分市场中哪些设置有效，
- 您看重细致的设置选项。

选择 CPC 模式，如果：

- 您只想为买家对商品详情页的每次点击付费，
- 您想测试不同的付费模式。

此外，您还可以在我们的卖家学习中心 PRO WB 查看 [Wildberries 的推广资料](https://pro.wildberries.cn/past-events)。
