如何创建，更新或者删除WB API令牌

WB API 令牌是一组用于让外部系统访问您在 WB Partners卖家后台上店铺数据的唯一代码。本文将说明如何创建令牌。

重要规则

- 只有账号所有者可以创建和删除令牌；
- 令牌有效期为 180 天。到期前 3 天账号所有者将在 WB Partners 卖家后台收到通知；
- 令牌仅在创建时显示一次，请立即妥善保存；
- 更换账号所有者后，令牌将无法继续正常使用，新所有者需要重新创建；
- 每个店铺最多可创建 20 个有效令牌。

## 选择令牌类型

请根据您的目标选择适合的令牌类型：

- 服务令牌 — 用于连接官方解决方案目录中的云服务；
- 个人令牌 — 用于您自有的程序或部署在本地基础设施（on-premise，也称“本地版”或“盒装版”）的现成系统（ERP/CRM）；
- 基础令牌 — 用于在真实数据上进行测试，或在其他令牌类型不适用的情况下使用；
- 测试令牌 — 用于在沙盒中开发和调试，不会访问店铺真实数据。

关于令牌类型及其特点，可在相关文章《 [如何通过令牌连接 API](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-connect-via-api-with-token-china?categoryId=api-integration&goBackOption=prevRoute)》中了解更多详情。

在创建任意类型的令牌之前，请先进入个人资料中的 [“API 接口对接”版块](https://seller.wildberries.cn/api-integrations)，并点击“\+ 创建令牌”。

![](https://static-basket-02.wbbasket.ru/vol20/article-static/fc31403f-f06d-41e0-b367-81018d94129d.png.webp)

此时会打开令牌创建窗口，其中包含两个选项卡。请根据所需令牌类型选择对应的选项卡：

- “目录服务” — 用于创建服务令牌；
![img-16_9-b (2).png](https://static-basket-02.wbbasket.ru/vol20/article-static/747f29a8-cf00-4a6b-b57f-046a7d948160.png.webp)

- “手动集成” — 用于创建个人令牌、基础令牌和测试令牌。

![img-16_9-b (3).png](https://static-basket-02.wbbasket.ru/vol20/article-static/71520aaf-2ebb-481a-b692-b85ab2b82229.png.webp)

### 如何创建服务令牌

服务令牌用于连接 Wildberries 商家端“解决方案目录”中的云端服务。打开令牌创建窗口后：

1\. 选择服务。

进入“目录服务专用”选项卡，通过搜索找到所需服务，并在列表中点击其图标。

![img-16_9-b (4).png](https://static-basket-02.wbbasket.ru/vol20/article-static/7717b3a9-1f52-4a21-9ffe-e31e8b3b79f6.png.webp)

2\. 选择连接方式（如有）。

如果该服务支持 OAuth 2.0，界面会显示“通过 OAuth 2.0 简化连接”。建议选择该方式，以获得更顺畅的对接体验。

[如何通过 OAuth 2.0连接 API](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-connect-to-api-via-oauth-2-china?categoryId=api-integration&goBackOption=prevRoute)

如果该服务不支持 OAuth 2.0，则不会显示此选项。

3\. 选择服务版本（如需）。

目录中的部分服务提供两种版本—云端版与本地版（也称“盒装版”或“on-premise”）。

如果您连接的是云端服务，请继续创建服务令牌。

如果您连接的是本地版本，即安装在电脑或企业内部系统中的 on-premise 程序，则需要创建个人令牌。请前往“个人令牌”部分。

4\. 填写令牌参数。

创建服务令牌时，数据类别和相关设置会根据所选服务的要求自动填充，令牌名称也会自动生成。

您可以添加备注，以便做记录。此备注对卖家资料下的所有用户可见。创建后备注不可修改。

如果您仅使用服务的部分模块而非完整版本，可以手动调整预选的数据类别，但这可能会导致部分功能无法正常运行。

![img-16_9-b (5).png](https://static-basket-02.wbbasket.ru/vol20/article-static/90e8c9c4-396e-4f54-ae03-960cc7903ced.png.webp)

5\. 创建并保存令牌。

点击“创建”，系统会弹出包含令牌的窗口。点击“复制并关闭”，窗口将关闭，令牌也会复制到剪贴板。

令牌只显示一次。请务必将其保存在安全的位置，例如密码管理器或受保护的存储中。

将该令牌填写到您要连接的服务设置中。

令牌无法再次复制，但您可以随时在“API 接口对接”版块查看已创建令牌的信息，包括：有效期、名称、访问级别、数据类别等。

![img-16_9-b (6).png](https://static-basket-02.wbbasket.ru/vol20/article-static/bcb85b5d-51b0-4d7c-b0c5-0d7d9cc76334.png.webp)

服务令牌仅适用于所选服务，不能用于其他集成对接。

### 如何创建个人令牌

个人令牌用于将卖家的数据提供给您自有的程序或部署在自有服务器、租用服务器上的企业级 on-premise 系统。

随着后续更新，个人令牌将逐步开放更多数据类别，这些数据在基础令牌中不可用。相关变更我们会提前在新闻中说明。

当您需要连接自研程序或本地部署的成套系统（例如本地/盒装版 ERP、CRM）时，请使用个人令牌。

在您打开令牌创建窗口后：

1\. 选择令牌类型。

切换到“手动集成”选项卡，选择“个人令牌”。系统将提示此令牌不能用于云端服务。

![img-16_9-b (7).png](https://static-basket-02.wbbasket.ru/vol20/article-static/b0ceb0d4-5f87-44bc-ab2c-d9a732bef51e.png.webp)

2\. 填写令牌参数。

输入令牌名称。名称中需明确此令牌用于连接哪套系统，例如：“公司服务器上的 1C”或“公司 ERP 系统”。

选择访问类别，勾选需要访问的 WB API 数据类别。

个人令牌可访问的类别更广，包括用户管理等在其他类型令牌中无法使用的功能。同时，个人令牌仅适用于本地部署的解决方案，不能用于云端服务。

请选择其中一个访问级别：

- 读取与写入：通过该令牌可从 WB Partners 获取数据，也可在卖家后台中修改数据；
- 仅读取：通过该令牌只能获取数据，无法进行任何修改。

如果您不确定应选择哪些设置，请咨询公司内部的开发人员或 IT 负责人。您也可以参考关于 [集成方式的详细说明文章](https://seller.wildberries.ru/instructions/ch/ch/material/what-is-wb-api-and-how-to-work-with-it-china?categoryId=api-integration&goBackOption=prevRoute)。

您可以在备注栏中补充任意备注信息。备注对您账号下所有用户可见，创建后将无法修改。

阅读并确认风险提示：“我理解不应将令牌交给第三方。”

3\. 创建并保存令牌。

点击“创建”。系统会弹出窗口显示您的令牌。点击“复制并关闭”后，窗口将关闭，令牌会自动复制到剪贴板。

令牌只显示一次。请务必将其保存在安全的地方，例如密码管理器或受保护的存储空间。

随后将令牌提供给您的开发人员以加入集成代码，或由您自行将其添加到系统设置中。

令牌无法再次复制，但您可以随时在“API 接口对接”中查看该令牌的信息，包括有效期、系统名称、访问级别和数据类别等内容。

个人令牌不得交给第三方，也不得用于云端服务。此类令牌仅适用于您的自有基础设施，无法与云端服务配合使用。

### 如何创建基础令牌

基础令牌未来将仅提供对部分数据类别的访问权限。它适用于需要在真实数据上测试集成，或在服务令牌与个人令牌都不适用的情况下使用。

当您打开令牌创建窗口后：

1\. 选择令牌类型。

切换到“手动集成”选项卡，选择“基础令牌”。

2\. 填写令牌参数。

输入令牌名称。在名称中注明该令牌将用于连接哪套系统，例如：“仓库管理系统”或“用于分析的 CRM 系统”。

选择访问类别。勾选需要访问的 WB API 数据类别。

基于安全考虑，基础令牌无法访问部分数据类别，这些类别仅能通过个人令牌获取。

选择其中一个访问级别：

- 读取与写入：可通过令牌从 WB Partners 获取数据并在卖家后台中修改数据；
- 仅读取：只能获取数据，无法进行修改。

您可以在备注栏中添加备注信息。评论对您账号下所有用户可见，创建后不可修改。

3\. 创建并保存令牌

点击“创建”。系统会弹出窗口显示您的令牌。点击“复制并关闭”后，窗口将关闭，令牌会自动复制到剪贴板。

令牌只显示一次。请务必将其保存在安全的地方，例如密码管理器或受保护的存储空间。

随后将令牌提供给您的开发人员以加入集成代码，或由您自行将其添加到系统设置中。

令牌无法再次复制，但您可以随时在“API 接口对接”中查看该令牌的信息，包括有效期、系统名称、访问级别和数据类别等内容。

### 如何创建测试令牌

测试令牌是专门用于在隔离环境—即WB API沙盒中，安全开展集成测试与调试工作的工具。它无法提供对店铺真实数据的访问权限。请您使用测试令牌在生成的数据上开展集成开发与测试工作，如此一来，将不会对真实店铺信息产生任何影响。

当您打开令牌创建窗口后：

1\. 选择令牌类型。

切换到“手动集成”选项卡，选择“测试令牌”。

![img-16_9-b (8).png](https://static-basket-02.wbbasket.ru/vol20/article-static/4a3e3eb0-b77f-4e73-8937-38f0bb8528b9.png.webp)

您可以在备注栏中添加备注信息。评论对您账号下所有用户可见，创建后不可修改。

2\. 创建并保存令牌

点击“创建”。系统会弹出窗口显示您的令牌。点击“复制并关闭”后，窗口将关闭，令牌会自动复制到剪贴板。

令牌只显示一次。请务必将其保存在安全的地方，例如密码管理器或受保护的存储空间。

随后将令牌提供给您的开发人员以加入集成代码，或由您自行将其添加到系统设置中。

令牌无法再次复制，但您可以随时在“API 接口对接”中查看该令牌的信息，包括有效期、系统名称、访问级别和数据类别等内容。

测试令牌仅适用于沙盒环境，不允许访问真实店铺数据。无需选择数据类别——令牌会自动开放沙盒中可用的所 有类别。访问级别也已默认设置为读取与写入。

## 创建令牌后

- 将令牌交给开发人员，或将其添加到服务设置中。
- 测试集成—确保数据正确传输。
- 设置令牌更新提醒—大约在 160-170 天后。
- 做好记录—记下令牌用于哪个集成。

## 如何删除令牌

在任何安全威胁下，例如令牌可能泄露给第三方时，应立即删除令牌：

1. 进入“API 接口对接”板块。
2. 在列表中找到需要删除的令牌，点击“删除”。
3. 确认删除。
4. 创建新的令牌，并在集成系统的设置中更新。

如果您在账户中发现可疑操作，请联系 Wildberries 客服：在“个人账户安全”类别中创建消息，主题选择“未经授权的登录”。

## 如何更新令牌

令牌有效期为 180 天。过期后，如果不更新令牌，集成将停止工作。

建议在令牌到期前两周在日历中设置提醒，并在到期前 7–14 天更新令牌。

在令牌到期前三天，您将在 WB Partners 卖家后台中收到通知。

更新令牌步骤：

1. 打开个人资料中的“API 接口对接”板块。
2. 找到需要更新的令牌。
3. 点击“复制”按钮——将打开一个新的令牌创建窗口，设置与原令牌相同。确认创建并复制新令牌。
4. 在所有使用该令牌的系统中，将旧令牌替换为新令牌。
5. 在几天内检查新令牌下的集成是否正常工作。
6. 只有在确认新令牌正常工作后，才能删除旧令牌。

## 令牌使用安全规则

令牌类似于您个人资料的密码，但它不是人为使用，而是由程序使用。

使用令牌时，为保护数据安全，需要遵守以下重要规则：

1. 像保护密码一样安全地存储令牌。建议使用密码管理器或受保护的存储空间，不要将令牌记录在文本文件或即时通讯工具中。
2. 限制令牌访问权限。只有负责 API 集成的员工才能访问令牌。
3. 记录令牌有效期。可将有效期记录在密码管理器或其他安全位置，以便及时更新令牌。
4. 管理令牌记录。记录每个令牌的创建情况及使用的服务，以便在必要时快速停用。
5. 停止使用某个服务时，应立即删除对应令牌。如果停止与开发人员合作，请重新生成令牌并在所有系统中替换，然后删除旧令牌。

在向他人提供令牌时，意味着对方可访问您店铺和个人资料中的信息，其中可能包含个人数据。因此，在向合作伙伴、集成商或开发者提供访问权限前：

- 确保您信任接收方，
- 必要时控制并限制访问权限。

## 常见问题

能找回丢失的令牌吗？

令牌仅在创建时显示一次。如果未保存，需要删除旧令牌并重新创建。

更换个人账户所有者后会怎样？

令牌将无法正常工作，新所有者需要重新创建所有令牌。

可以创建多少个令牌？

每个个人账户最多可创建 20 个有效令牌。

可以延长令牌有效期吗？

令牌无法技术性延长。必须在旧令牌到期前创建新令牌。
