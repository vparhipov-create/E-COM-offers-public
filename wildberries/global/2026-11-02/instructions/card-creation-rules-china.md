商品信息填写规则

## 为什么正确填写商品信息非常重要？

正确填写商品信息是成功销售的基础。我们建议遵循以下规则。为了确保您的商品信息能够被系统良好地索引到，并且买家能够在搜索和筛选中看到它们，请确保您提供唯一且完整的详细信息，避免重复。

示例：如果您选择了“连衣裙”类目，并在描述中写了“适合女孩的白色空气感毕业舞会连衣裙”，您的商品将会根据以下关键词进行索引：“连衣裙”、“白色连衣裙”、“毕业舞会连衣裙”、“女孩连衣裙”、“白色毕业舞会连衣裙”、“白色毕业舞会”等其他词组的组合。如果您写了“有趣的连衣裙 彩色连衣裙 毕业舞会连衣裙 带猫图案的连衣裙”，文本将会自动缩减为“有趣的彩色毕业舞会连衣裙带猫图案”。

如果您在附加字段中填写无法被索引的内容，商品将无法进入筛选器，买家将看不到该商品。

示例：成分“棉花”是正确的值，而成分“棉花 纸 木材”将无法被筛选器识别。

如果填写错误，系统将自动修正商品信息。

## 语言

如果您使用的是俄语界面，文本需要直接用俄语输入。翻译出来的俄语必须是专业的。如果文本中有很多错误或描述不清晰，买家将难以在搜索中找到您的商品，并且商品页面的排名也会降低。

如果您不懂俄语并且使用的是中文界面，所有字段需要用中文填写。保存商品信息后，系统会自动将文本翻译成俄语。

## 品牌

品牌是指商品的工厂商标或商标，必须按照商品的标识进行填写。

- 不要在品牌字段中填写您公司的名称。
- 品牌名称不能以符号开头，也不能与商品类目重复。
- 在“品牌”字段中不能使用斜杠（/）或重复的单词。

## 商品名称

商品名称是商品页面标题中显示的名称，也会展示在商品目录中。

商品名称只需包含最重要的信息，不应包含商品描述，描述应该通过其他参数和描述字段填写。

在目录中，商品名称可能不会完全显示，因此建议在选择词序时考虑这一点。

俄语商品名称应包含不超过60个字符，理想情况下为40个字符。

商品名称中不应使用大写字母，除非是官方或常见的缩写。

根据规则，商品名称中不能包含同义词、重复词汇或任何与商品名称无关的词组。

请检查商品名称中是否包含搜索热门关键词。为选择合适的名称，可参考最受欢迎的搜索词报告。点击“分析”标签 → “热门搜索”。

### 商品名称中的常见错误

| 错误 | 如何修正 |
| --- | --- |
| 空白字段 | 填写商品名称 |
| 指明性别，例如“男生T恤” | 删除名称中的性别信息，并在商品特征中注明。 |
| 列举商品名称，例如“女款背心、<br>女士针织背心、办公室用背心” | 删除重复和同义词 |
| 多余的细节，描述中用词过多，<br>例如“适合女生的新年闪亮礼服” | 在名称中回答“商品上展示的是什么？<br>”避免多余的细节、使用建议和评价性判断，<br>这些内容最好放在商品描述中。 |

## 成分

成分是构成成品（商品）的各个部分（元素）的总和。每个成分必须单独列出，并且不得使用缩写。

成分中不能包括商品本身——如洗发水、油、裙子、手机等。

示例：对于“洗发水”这个商品，在“成分”字段中应该填写的不是“洗发水100%”，而是详细描述它的成分，例如：“椰子硫酸钠；甘油；葡萄糖苷；氯化钠；丁二醇；尿素；谷氨酸；精氨酸；赖氨酸；甘氨酸；尿囊素；乳酸”。

## 特征和附加参数

一，特征和参数

我们建议正确填写所有您认为重要的特性。每个参数都应符合系统中列出的值。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/888495ee-cc89-4b82-b67a-dcf712b3cbc7.png.webp)

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/9c4490b8-43f9-4329-8113-d3216ca1c25a.png.webp)

特性字段中不应使用大写字母，除非是官方或常见的缩写。

在特性中必须填写系统中列出的值。

不允许通过逗号列出多个值，请按键盘上的“Enter”键单独保存每个值。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/7960fb34-e662-4f0b-a065-8e42f9762d88.png.webp)

大多数商品会根据商品信息中列出的类目展示，但通过附加参数，一些类目会被显示在额外的分类中。因此，正确填写所有参数非常重要。

在不同的附加字段中，值不应重复。

二，俄罗斯尺寸

中国的尺码与俄罗斯的尺码不同。目前商品信息中无法自定义尺码表。因此，我们建议在图片中添加您商品的尺码参数。商品描述中不需要写尺码，这会对商品排名产生不良影响。

三， 产品价格

商品价格只能以人民币（元）填写。

四， 常见错误

| 错误 | 如何修正 |
| --- | --- |
| 未填写商品的尺寸和包装重量 | 商品的尺寸和包装重量不能为零。<br>请填写所有字段，避免罚款。 |
| 特性用大写字母填写 | 请修正文本。避免使用大写字母来表示参数值。 |
| 描述过长 | 删除重复和同义词，之后避免使用 |
| 尺码或价格不正确 | 请检查尺码，并在照片中添加商品的尺码表。<br>价格需以人民币标注。 |

## 商品描述

商品描述是非常重要的参数之一，用来最大程度地准确描述商品。它应该简洁、真实且有价值，同时符合商品本身的特点。

在描述中必须指出商品对买家的实际效果和使用益处，这将帮助买家做出购买决策。

商品描述中字符数量取决于商品的父类目：

| 类目 | 俄语字符数量 |
| --- | --- |
| 健康，药品 | 5 000 |
| 家居，保险 | 4 000 |
| 汽车电子，轿车，家具，食品，<br>运动营养和化妆品，智能家居与安全，<br>窗帘及配件，珠宝 | 3 000 |
| 酒类产品，数字内容 | 1 000 |

请记得，商品页面中还有其他字段，关于商品功能或特性的部分信息还可以通过其他商品特征进行说明，而不仅仅是在描述中。

禁止在描述中使用域名，如.cn、.ru、.net、.com、.io等。禁止在描述中写您的商品货号和其他卖家商品的货号。 描述中不得包含标签或任何其他SEO关键词。网站的搜索系统会自动对文本进行索引并生成搜索查询。所有需要在查询中展示的词语，必须以正常方式写入商品描述中，避免使用特殊符号和确保有空格分隔。

### 商品描述中的常见错误

| 错误 | 怎么做？ |
| --- | --- |
| 没有描述 | 请填写商品描述字段，告诉买家它的优势。 |
| 描述中有很多重复的词和相似的句子 | 删除重复内容、尺码、颜色和商品选项的列举。<br>只保留与该商品相关的信息。 |
| 提到了与商品无关的品牌 | 删除描述中与您的商品无关的品牌。 |
| 信息矛盾 | 清晰地说明您的商品适合哪些用途。如果商品并不是万能的，<br>请不要试图将其描述为万能。 |

## 配件清单

在此列出买家下单后会收到的所有物品及数量。

例如：如果您出售一款大衣，在此字段填写：“大衣、腰带”。

如果是化妆品套装，请详细列出其中包含的商品。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/70b4236b-e9a4-4849-a76c-32b695113d92.png.webp)

配件清单最多可填写 12 个条目，各个条目内容是灵活的。

不应包含商品参数或详细描述。

## 总结

请检查您的商品页面是否正确填写，以下是关键点：

- 专业的俄语翻译
- 规范的商品名称
- 适合的商品类目及完整的商品参数
- 正确的尺码和价格
- 商品描述中突出重点
- 价格必须以人民币（元）为单位，而非卢布
