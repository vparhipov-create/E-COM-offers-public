商品评分报告

该报告展示您的商品获得的评分和评论，以及它们与销售之间的关系。报告数据有助于分析买家满意度，并做出影响卖家评级和销售业绩的决策。该报告免费向所有卖家开放。

## 报告用途

通过该报告，您可以：

- 追踪评分和评级的动态变化；
- 找出评分较低的商品并分析原因；
- 查看评级变化对订单和成交的影响。

例如，您在报告中注意到低评分出现激增。您可以设定相应时间段，查看销售指标，评估收到的评论数量，并直接跳转至“评论”板块，了解买家喜欢或特别不满意的方面。

## 如何使用报告

查看报告请前往“分析” → “商品评分”。数据每日自动更新，更新时间显示在右上角。报告页面默认显示过去7天（不含当日）的数据，但您可选择最长365天的任意时间段，并与其他时段进行对比。

## 设置与筛选

页面顶部为时间段设置和筛选器。

报告中默认显示与上周的对比——数据会自动与所选时间段之前的同期进行对比。默认对比周期为一周。您可根据需要选择最近365天内的任意其他时段进行对比。这样可评估促销活动、商品矩阵调整及您对商品所做的任何操作带来的效果。

筛选器可帮助您按需定制报告：可按品类、品牌、商品编号和标签筛选数据。在主筛选器中，还可选择额外排序：“已隐藏商品”——因评级过低而被隐藏的商品详情页。

还可使用“不包含零销售商品”筛选功能——开启后，报告仅显示所选时间段内有销售记录的商品。若不开启，报告将展示所有商品。

报告中卖家总评级数据仅受所选时间段的影响，其他筛选器影响报告内除评级外的所有数据。

## 卖家评级

该组件显示您在所选时间段（默认最近一周）的评级、与前一周期的变化对比，以及与销售同类商品的其他卖家的对比。对比时我们综合考虑您的评级和评论数量。

彩色刻度显示您的评级对搜索结果中商品隐藏的影响。组件右侧为提升评级的建议。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/597c49ba-2f14-4d92-b0c9-9e6be4d83070.png.webp)

新卖家在评级尚未计算时，组件中显示为0

您的评级影响商品在WB搜索结果中的可见性：如果评级过低，商品将不会在搜索结果的查询中展示。以下是评级刻度中不同颜色的含义：

| 色阶 | 卖家评级 | 搜索结果中的商品 |
| --- | --- | --- |
| 🟥 红色 | 0–3.1 | 所有商品均从搜索结果中隐藏 |
| 🟧 橙色 | 3.1–3.6 | 仅4星及以上的商品详情页显示 |
| 🟩 浅绿色 | 3.6–4 | 超过10条评论时，评级低于3的商品详情页隐藏 |
| 🟩 绿色 | 4–5 | 商品不隐藏，并在搜索结果中获得曝光提升 |

如果部分商品因评级过低被隐藏，报告页面将显示带有其数量的横幅。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/fce3102d-4c70-4bb2-a9c5-88637ff1c0a9.png.webp)

### 卖家评级计算方式

该指标根据买家对您商品评分的平均值计算。

计算时采用近三年内最新的20,000条有效评分和评论。新近的评论和评分在评级计算中权重更高。因此，近期给予高评价的满意买家越多，您的卖家评级就越高。

关于卖家评级计算方式及其对商品搜索结果展示影响的详细说明，请参阅本 [指南](https://seller.wildberries.ru/instructions/ch/ch/material/china-sellers-rating?categoryId=ratings&goBackOption=prevRoute)。

## 评分增长

该组件显示所选时间段内新增的有效评级评分数量，以及与前一对比周期的差异。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/c31465f5-5d6d-48c2-b977-4a7fbe92a173.png.webp)

这里包含两个图表：按日、周或月展示的动态折线图，以及按星级分布的评分刻度。将鼠标悬停在图表上可查看详情，也可直接跳转至“评论”板块。

有时增长值可能显示为负数——这是因为未通过审核的评论仍被计入，导致最终值出现负向波动。组件和表格中不统计与商品无关的评论及补充评论的初始版本。

## 表格

报告主体为按商品展示数据的表格，包含两个选项卡：

- 评论与评分分布。此处显示每个商品的评论评级与类目平均值的对比、评论数量、星级分布及被排除的评论数量。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/261d3697-cbc6-4e0a-8c7c-fda1160aeaba.png.webp)

表格中每个数值均显示与所选对比周期的变化。例如，本周买家对某商品留下7条5星评价，而上周为8条5星评价。则“5星”列中将显示7（所选周期内的评价数量），下方显示红色数字1及向下箭头（比对比周期少1条）。

| 指标 | 说明 |
| --- | --- |
| 商品评论评级 | 商品评级及与类目平均值的对比 |
| 周期内总评论数 | 计入评级的买家评论数量 |
| 5/4/3/2/1 | 按星级分布 |
| 已排除 | 周期内被排除出评级计算的评论总数 <br>该列数值可能为负数——如果之前被排除的评论在审核后重新计入评级。 |

在“评论与评分分布”选项卡中，表格上方设有“按商品合并分组”开关。

开启后，可查看合并商品详情页（而非单张商品详情页）的汇总数据。

合并商品是指将不同规格（如不同颜色的连衣裙或长裤）的商品归入同一商品详情页。对买家而言，这些商品显示为可切换选项的单张商品详情页。

开启开关后，表格数据将按合并商品详情页分组：

- 首行显示合并商品详情页汇总；
- 下方显示其中所有规格商品的明细。每个规格均可查看评级、评论和评分。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/5ce2150d-a2c2-4e82-8080-b3e4640a8927.png.webp)

所选时间段内无数据的商品编号不纳入分组。例如，尚无评论的新商品详情页不会在表格中显示。

合并商品详情页上带有额外标记：灰色标签显示该合并中包含的规格数量。

核心指标。这些数据有助于了解商品评级与关键业务指标（订单、成交、成交率及取消）之间的关系。例如，可发现评级高于4.8的商品成交率显著高于评级4.7的商品。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/c6f3bbf2-09a2-4508-9aa5-977fb6ed43f8.png.webp)

| 指标 | 说明 |
| --- | --- |
| 商品评论评级 | 同第一选项卡，商品评级及与类目平均值的对比 |
| 已下单商品（件） | 商品订单总数 |
| 已成交商品（件） | 商品成交数量，按成交日期计算 |
| 成交率 | 成交数量与成交及取消总数之比，运输中商品不计入 |
| 已取消商品（件） | 退回或取消的商品数量，按取消或退货日期计算 |

数据可按任意指标排序，表格默认按评级排序。在表格设置中可调整列顺序及显示或隐藏列。点击表格右上角的⚙️图标即可操作。

### 导出为Excel

表格数据可导出为Excel文件。导出时保留您在报告中应用的所有设置，包括所选时间段和筛选条件。文件包含每个商品编号的明细及所有指标定义。

点击表格右上角的📄图标即可导出。
