如何正确设计饰品销售的商品详情页

根据俄罗斯联邦法律（第41-FZ号联邦法）和Wildberries平台政策，外国法人实体严禁销售珠宝饰品。

您只能在“饰品”类目中进行销售。所有上传至系统的商品必须符合该类别。

为确保您的商品通过审核且不被误判为“珠宝饰品”而屏蔽，请严格按照商品特性填写指南操作。这些规则是强制性的，将帮助您正确分类商品，避免来自平台和监管机构的投诉。

## 如何区分珠宝饰品与饰品

如果商品由带有成色标记的贵金属或天然宝石制成，则视为珠宝饰品。合成宝石和人造宝石不属于天然宝石。

此外，贵金属涂层也不构成珠宝饰品的判定依据。

因此，符合以下条件的任何饰品均视为饰品：

- 由非贵金属制成；
- 不含天然宝石镶嵌。

## 珠宝饰品材料

### 贵金属

根据法律规定，贵金属仅包括：

- 金；
- 银；
- 铂；
- 铂族金属：钯、铱、铑、钌、锇。

贵金属制成的珠宝饰品必须带有成色标记：

- 金 — 999、958、916、875、750、585、583、500、375 或 333；
- 银 — 999、960、925、875、830 或 800；
- 铂 — 950、900、850 或 585；
- 钯 — 850 或 500。

### 天然宝石

根据法律规定，天然宝石仅包括：

- 钻石和成品钻石；
- 祖母绿；
- 红宝石；
- 蓝宝石；
- 亚历山大石；
- 天然珍珠（未经处理及经处理）；
- [符合多项标准](https://base.garant.ru/12114068/#block_1000) 的独特琥珀形成物。

仅天然海珠和淡水珍珠被视为宝石，即在软体动物壳内天然形成，未经人工干预。

## 饰品材料

### 非贵金属

饰品中最常用的材料为黄铜、钢、钛及首饰合金。较少使用的有纯铜、锌、钨、镍和锡。

### 非宝石

| 半宝石 | 石英、托帕石、石榴石、绿柱石、碧玺、欧泊、锆石、金绿宝石，以及月光石、有机宝石或装饰性宝石 |
| --- | --- |
| 合成宝石 | 人工培育的矿物，其化学成分、物理和光学特性与天然对应物相同 |
| 人造宝石 | 人工制造的宝石，无天然对应物。其中最著名的是立方氧化锆 |

## 如何正确设计饰品商品详情页

首先请确认您的商品符合饰品类目的要求即

- 由非贵金属制成
- 不含天然宝石镶嵌

例如：

不允许的情况：

585金戒指镶嵌缟玛瑙

缟玛瑙属于半宝石但戒指本身由贵金属制成属于珠宝饰品

允许的情况：

黄铜戒指镶嵌缟玛瑙

半宝石搭配非贵金属属于饰品合规

### 饰品描述

请不要在饰品商品的名称、描述、图片和成分中使用以下词语：

描述宝石时，禁止使用“драгоценный”（珍贵的）和“природный”（天然的）：

\- 不允许：драгоценный природный топаз（珍贵天然托帕石）

\- 允许：натуральный топаз（天然托帕石）

描述非贵金属珍珠时，禁止使用“природный”（天然的、自然的）。如需强调珍珠非人工合成，可使用“натуральный”（天然的）：

\- 不允许：колье с природным натуральным жемчугом（带有天然天然珍珠的项链）

\- 允许：колье с натуральным жемчугом（天然珍珠项链）

描述商品颜色时，禁止使用“золото”、“золотой”、“серебро”、“серебряный”。请使用商品详情页中的“颜色”字段，选择“золотой”（金色）或“серебряный”（银色）。在其他所有情况下，使用“золотистый”（金色的）和“серебристый”（银色的）。

| 不允许使用 | 允许使用 |
| --- | --- |
| «колье в золоте»<br>“金色项链” | «колье в золотистом цвете»<br>“金色调项链” |
| «цвет: золото»<br>“颜色：金色” | «цвет: золотистый»<br>“颜色：金色调” |
| «золотой оттенок»<br>“金色调” | «золотистый оттенок»<br>“金色调” |
| «серьги серебро»<br>“银色耳环” | «серьги серебристые»<br>“银色调耳环” |
| «в цвете белое золото»<br>“白色金色” | «в бежево-золотистом тоне» или «цвет: золотистый»<br>“米金色调”或“颜色：金色调” |
| «цепочка из серебра» (если это бижутерия)<br>“银质项链” | «цепочка серебристого цвета» (материал — сталь/сплав)<br>“银色项链”（材质为钢/合金） |

不规范的描述可能会误导买家，系统也会将饰品详情页中的商品误判为珠宝饰品，从而因违规而屏蔽该详情页。

## 关于成色标注

若饰品表面镀有贵金属，可在商品描述中标注其成色，但必须明确指向镀层。在其他任何情况下，即便仅标注成色数字，也视为违规。

例如：

不允许：

黄铜戒指，585金

允许：

黄铜戒指，镀585金

请在创建商品详情页时使用专用字段“镀层”。在该字段中填写所需镀层材料：“金”或“银”。
