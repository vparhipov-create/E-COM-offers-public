# WB Global: продажи из Китая в Россию

Публичный комплект на **02.11.2026** для китайских компаний, продающих покупателям в России. Начните с [русского отчёта](REPORT.md); отдельные оригиналы и инструкции перечислены в [реестре](INDEX.md).

## Состав

- 31 исходный PDF: оферта №29 (75 страниц), отдельная лицензия и связанные документы, включая вложенные ограничения и исторические тарифы.
- 151 страница справочного центра: 143 полных текста и восемь публичных уведомлений об ограничении доступа.
- [Девять файлов для рабочего проекта](upload): три PDF и шесть Markdown. Сборник приложений содержит 193 страницы; соответствие оригиналам — [карта страниц](upload/page_map.json).
- [Каталог и контрольные суммы](manifest.json), даты источников и [границы охвата](COVERAGE.md).

Подключайте раздел через [общую инструкцию для ИИ](../../../AI_START_HERE.md): помощник сам получает документы из репозитория и проверяет обновления.

## Применимость и ограничения

Китайская оферта №29 определяет продавца как организацию за пределами РФ. Регистрация компании, KYC, доступность модели, выплаты, импортная схема и условия конкретного перевозчика требуют проверки по конкретному продавцу. Этот обзор не подтверждает подключение определённого аккаунта.

Архив прежних китайских оферт пока не получен; восемь закрытых инструкций не объявлены прочитанными. Исходные языки сохранены; полного перевода всех китайских статей нет. Изображения и видео даны ссылками, их двоичные копии не включены. Исторические тарифы не объявлены текущими. [Подробный охват](COVERAGE.md).
