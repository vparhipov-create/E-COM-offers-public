商品合并

同一类目中颜色、体积或口味不同的商品，可以合并到同一个商品详情页中。例如，1升和2升的柠檬水，或者同一款式的白色、灰色和黑色连衣裙。

对买家而言，这看起来就像是带有不同变体的同一件商品：可以方便地订购多件，并在自提点选择最合适的。

在此类商品详情页中，所有商品变体的总评分和评论不会合并，买家可以分别查看单个商品详情页的评论和评分。

## 哪些商品可以合并？

要合并的商品必须属于同一类目，并具有相同的通用属性。在填写商品信息时，如果您选择了类目，页面左侧会出现提示框，说明哪些属性是通用的，哪些是可变的。

例如，在填写智能手机信息时，系统会提示：

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/1632f52a-3f37-4559-a8a0-2966b58c5731.png.webp)

因此，如果智能手机的品牌和型号一致，就可以进行合并。

|  | 可以合并 | 不可以合并 |
| --- | --- | --- |
| 洗发水 | 不同容量的瓶装 | 供不同发质使用 |
| 水龙头 | 不同颜色 | 不同型号 |
| 智能手机 | 内存为16GB和32GB | 不同品牌 |
| 床垫 | 不同尺寸 | 不同品牌 |
| 酒柜 | 不同颜色 | 不同型号 |

对于 “美容” 和 “日用化学品” 类目中的部分商品，只有在合并前为每个商品变体正确填写可变特征，才可以合并商品详情页。否则将无法保存合并后的商品详情页。

| 商品 | 商品变体的必填特征 |
| --- | --- |
| 油类化妆品 | 容量、香味 |
| 卫生巾 | 吸收量、数量 |
| 洗衣粉 | 容量、重量 |
| 发胶 | 容量、定型强度 |

在合并这些商品的商品详情页时，系统会检查：每个商品变体是否填写了这些特征，并且各变体在至少一个特征上存在差异。例如，对于油类化妆品油，容量可以相同，但香味必须不同。如果必填特征未填写或填写有误，将无法保存商品详情页。

如何将商品色号合并到商品详情页中

当您将色号合并到同一个商品详情页后，买家可以更方便地对比并选择所需的颜色。

目前仅适用于“美妆”品类下的“唇膏”和“唇彩”商品。

要将唇膏或唇彩的色号合并到同一商品详情页中：

1. 为所有商品变体添加图片。
2. 在动态特征中必须包含色号名称。请检查并为所有变体填写色号名称。

![](https://static-basket-02.wbbasket.ru/vol20/article-static/00859278-147d-4f35-91ef-d6a870e3ed7b.png.webp)

3.确保没有相同色号名称的商品变体。否则，买家仅能以图片轮播的形式看到变体（稍后会展示其效果）。

4.在商品详情页的“色号”字段中，点击色号名称旁边的 ✏️ 图标，在弹出窗口中添加色样，然后保存。

![](https://static-basket-02.wbbasket.ru/vol20/article-static/29c3e12e-ade3-49c0-b832-7420e55473d9.png.webp)

![](https://static-basket-02.wbbasket.ru/vol20/article-static/372b6fb4-c729-4979-905b-fb1c08ad3677.png.webp)

图片要求：

- - - 分辨率：不低于 700×933 像素；
    - 格式：JPG、PNG 或 WEBP；
    - 白色或中性背景；
    - 无滤镜、修图或失真的光线；
    - 无文字、标志或其他无关物品。

5.为每个变体添加色号图片。上传图片后，将进行审核，审核通常不超过一小时。

## 如何创建包含多个变体的商品

1. 在卖家后台顶部菜单中点击“商品与价格” → “商品详情页” → “添加” → “单个商品”。


![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/7c1dd290-df95-436d-a49f-41be26894923.png.webp)

2. 输入商品名称，选择商品分类，然后点击“添加选项”。
3. 填写所有商品共用的属性字段。哪些是共用属性，系统会在左侧窗口中提示。如果将鼠标悬停在提示中的属性上，右侧会高亮显示需要填写的字段。
4. 如果您更改了某个商品变体中的共同属性，其他选项的对应属性也会自动同步更新。接着，请填写那些可以不同的属性，同样可以参考左侧窗口中的提示。

## 如何合并已创建的商品

如果您已经有多个商品，它们的分类和共用属性相同，您可以将这些商品合并成一个。

- 在卖家后台顶部菜单中点击“商品与价格” → “商品详情页”；
- 选择您希望合并的其中一款商品并点击它。随后在右侧打开的面板中点击“编辑”。
- 在页面左侧可以看到“变体”模块，系统会提供几种添加新变体的方式，请选择“从您的卡中”；
- 输入您希望合并进来的商品编号；




![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/583c3f8f-b004-4c5e-8e87-9cd3bbd565a3.webp.webp)

- 点击“合并选定的变体”。您最多可以合并 30 个商品；
- 全部设置完成后，点击“继续”。
- 如果出现错误且商品详情页无法保存，请检查所有商品变体是否都填写了必填的可变特征。

对于 “美容” 和 “日用化学品” 类目中的部分商品。例如油类化妆品、卫生巾、洗衣粉和发胶，如果未填写这些特征，将无法合并并保存商品详情页。

## 如何将商品移出合并商品

如果您希望某个商品不再与其他商品合并，请在“商品”板块中找到对应的商品：

- 点击该商品并选择“编辑”；
- 在左侧找到该商品的缩略图，点击“更多” → “列为独立商品”。该商品将被保存为一个独立的商品。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/749c8234-7395-4f6d-8d13-539f733a11c7.png.webp)

同样的位置还可以删除不需要的商品变体。
