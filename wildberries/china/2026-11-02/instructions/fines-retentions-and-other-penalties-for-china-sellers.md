卖家的罚款、扣款及其他处罚

## 要约中哪一条提到了罚款相关信息？

有时卖家可能会违反规定。这可能导致运营问题，给Wildberries造成损失或给买家带来不便。因此，我们要求您更加谨慎，并对违规行为进行罚款。

违规可能发生在不同阶段：创建商品时、供货过程中或其他情况下。请了解可能产生的罚款、扣款及其他处罚。

有关违反平台规则的责任详情，请参阅要约第9.9条“双方责任”。

## 商品信息

### 商品信息中尺寸信息错误

当订单到达Wildberries分拣中心时，会进行尺寸测量。如果尺寸信息错误（例如低估尺寸），将收取罚款。计算公式为：适用于商品编号的配送服务费率 × 尺寸系数

罚款金额：在商品单位交给买家或买家在运输后拒收商品时，如果这些商品单位的货号系数 (KA) 值大于 1（一），尺寸错误的罚款按商品每一个单位计算（Wg）。商品每一个单位的罚款金额构成卖家因尺寸错误而应支付的罚款总额。

商品每一个单位的罚款应按以下公式计算：

Wg = Tl × KA,

Tl 是在提供配送服务（第 13.1条）时适用于货号的费率（根据野莓规定的商品尺寸 (Vf)）；

同时，如果单件商品的尺寸不符罚款少于100约定单位，则按100约定单位计算；如果超过10,000约定单位，则按10,000约定单位。

何时将会罚款：在交付商品时，如果商品信息展示了错误的尺寸。

如何避免：在商品信息中添加正确的商品及其包装尺寸。

显示位置：财务报告 → 销售报告 → 每周报告 → 在“操作”列的三个点 → 详细信息 → 向买家交付货物的服务。

罚款依据：要约第13.3.11条。

### 关于商品可订购性的误导信息

罚款金额：25,000约定单位

何时将会罚款：当商品信息中使用误导买家关于商品可订购性的图片时，包括带有“商品已售罄”、“即将上市”、“暂时缺货”等类似含义的文字的图片。

如何避免：在商品信息中添加最新的商品图片，并避免使用可能误导买家关于商品可订购性的文字。

显示位置：财务报告 → 销售报告 → 每周报告 → “操作”列中的三个点 → 详细信息→ 配送、罚款和附加费用类型。

罚款依据：罚款清单第13条。

### 承诺评论报酬

罚款金额：每发现一次违规行为，罚款50,000货币单位。

罚款触发条件：如果卖家通过商品详情页、包装内插页或任何其他方式向买家承诺金钱或其他报酬以换取评论。

罚款依据：罚款清单第3项。

### 将商品归类至错误的商品类目中

罚款金额：25,000货币单位

何时将会罚款：当商品被放置在与其不匹配的商品类目中时。

如何避免：在发布商品时 [参考相关指南](https://seller.wildberries.ru/instructions/ch/ch/material/product-cetegories-china?categoryId=about-item-card&goBackOption=prevRoute)。

显示位置：财务报告 → 销售报告 → 每周报告 → “操作”列中的三个点 →详细信息 → 配送、罚款和附加费用类型。

罚款依据：罚款清单第13条。

### 承诺评论报酬

罚款金额：每发现一次违规行为，罚款50,000货币单位。

罚款触发条件：如果卖家通过商品详情页、包装内插页或任何其他方式向买家承诺金钱或其他报酬以换取评论。

罚款依据：罚款清单第3项。

### 缺少强制标记

罚款金额：每发现一次违规行为，罚款50,000货币单位。

罚款触发条件：如果根据2022年7月14日第255-FZ号联邦法，商品应附带特殊文字说明，而卖家未添加或未注明信息产品标识（18+或“禁止儿童”）。

罚款依据：罚款清单第4项。

### HS编码填写错误

罚款金额：每件交付给Wildberries的商品因HS编码填写错误，罚款1,500货币单位。

罚款触发条件：如果商品详情页中未填写需强制标记商品的HS编码，或为无需标记的商品填写了对应强制标记类目的HS编码。

罚款依据：罚款清单第12项。

## 订单

### 未完成的订单（卖家取消）

罚款金额：违反商品交付期限的罚款为商品对应的四倍佣金。四倍佣金最高不超过商品价格的50%。单件商品罚款上限为3,000货币单位。如果订单因卖家账户遭非法访问期间被取消（因卖家未履行登录名和密码保密义务所致），该期间内所有未交付订单的罚款总额不超过100,000货币单位。

何时将会罚款:

- 在卖家单方面拒绝履行已生成订单且商品有库存的情况下；
- 在订单因商品交付期限（120小时）届满而自动取消，且未实际交付给Wildberries的情况下。

罚款金额：订单零售价格的50%，但不少于100约定单位。

何时将会罚款：如果卖家取消了已收到的订单，或订单在买家下单后120小时内未发货或分拣。

如何避免：检查实际库存与卖家后台中的库存。如果没有及时重置，买家可能会订购缺货的商品。

显示位置：财务报告 → 销售报告 → 每周报告 → “操作”列中的三个点 → 详细信息 → 配送、罚款和附加费用类型。

罚款依据：罚款清单第14条。

### 商品替换

罚款金额：订单金额的100%，但不少于100约定单位。

何时将会罚款：当发货的商品与商品页面中的描述不符时。

如果订单中包含多个商品，而卖家仅错误发货了其中一个商品，仍然会产生罚款。罚款金额将根据错误发货的商品价值计算。

例如，卖家发送了裤子而不是T恤。卖家将因未完成订单（发送与描述不符的商品）而被罚款。

如果卖家发送了黑色S码的T恤，而买家订购的是白色M码的T恤，则问题在于错误的标记：商品本身是正确的（T恤），但其特征（例如颜色或尺寸）不符。在这种情况下也会产生罚款。

如何避免：确保商品与您的标记一致。在仓库中拣货时使用配货清单，这样可以减少混淆。

显示位置：财务报告 → 销售报告 → 每周报告 → “操作”列中的三个点 → 详细信息 → 配送、罚款和附加费用类型。

罚款依据：罚款清单第18条。

### 销售禁售商品

罚款金额：在网站上发布禁售商品或将其供应至仓库时，罚款25,000约定单位。易燃商品：发布商品或供应至仓库时，罚款100,000约定单位。

何时将会罚款：当在网站上发布俄罗斯联邦及其他配送国家法律禁止销售的商品时。禁售商品将被屏蔽。

如何避免：请查阅要约第9.2.3条中的禁售商品清单。

显示位置：分析 → 报告 → [隐藏商品](https://seller.wildberries.ru/analytics-reports/banned-products/blocked)。

罚款依据：罚款清单第2条。

## 商品供货

### 运送至其他分拣中心

罚款金额：每个违规发货订单总金额的30%，但不超过100,000货币单位。

何时将会罚款：如果交货点不在同一城市（以市政单位为界）范围内，或者卖家选择的交货点原本在某个配送区域内，而实际交货却发生在该区域之外。

如何避免：确保在您的仓库区域内发货。

显示位置：财务报告 → 销售报告 → 每周报告 → “操作”列中的三个点 → 详细信息 → 配送、罚款和附加费用类型。

罚款依据：罚款清单第9条。

### 超大型商品发货至错误仓库或分拣中心，或使用非指定装卸口

罚款金额：

1. 如果商品在卖家在平台上选择的地区范围内交付给Wildberries：每笔订单总价值的30%，但不超过100,000货币单位；
2. 如果商品在其他地区交付给Wildberries：每笔订单总价值的30%（无上限）。

何时将会罚款：如果卖家在创建超大型商品供货时指定了一个仓库或分拣中心，但实际将货物运送至另一个仓库或分拣中心。或者，如果卖家占用了仓库或分拣中心中未指定用于超大型商品装卸的装卸口。

超大型商品是指符合以下任一条件的商品：

- 包装后重量为25至100公斤，
- 包装后单边长度为120至400厘米，
- 三边长度总和为200至1200厘米。

如何避免：将商品发货至选定的仓库或分拣中心，并使用指定用于超大型商品的装卸口。

显示位置：财务报告 → 销售报告 → 每周报告 → “操作”列中的三个点 →详细信息 → 配送、罚款和附加费用类型。

罚款依据：罚款清单第10条。

### 包装中存在害虫

罚款金额：

- 首次违规 — 10,000货币单位；
- 再次违规 — 50,000货币单位；
- 第三次及之后每次违规 — 100,000货币单位。

罚款触发条件：如果交付商品的外包装中发现啮齿类动物、昆虫、鸟类及其他害虫，或发现其活动痕迹。

罚款依据：罚款清单第16项。

### 违反包装及标记规则

罚款金额：5,000货币单位。

罚款触发条件：在Wildberries仓库卸货时，违反第11.1.1条规定的商品包装及标记规则。

罚款依据：罚款清单第21项。

## 其他违规情况

### 违反Wildberries仓库行为规范

罚款金额：每次违规行为罚款200,000约定单位。

何时将会罚款：当发现卖家、其员工或与其一同进入仓库的人员存在违规行为时。

违规行为清单：

- 未经特别许可进入Wildberries区域；
- 绕过闸机或栏杆进入Wildberries区域；
- 在Wildberries区域内非指定地点吸烟；
- 在Wildberries区域内以超过20公里/小时的速度行驶；
- 在Wildberries区域内修理车辆或倾倒技术液体；
- 在Wildberries区域内非指定地点丢弃垃圾；
- 通过用于装载Wildberries物资的装卸口进入Wildberries建筑物；
- 未遵守Wildberries安保人员关于在区域内移动车辆的要求；
- 在酒精或药物影响下进入Wildberries区域，或携带俄罗斯联邦禁止流通的液体或物质；
