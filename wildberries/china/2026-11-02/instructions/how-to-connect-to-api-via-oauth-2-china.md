如何通过 OAuth 2.0连接 API

关于 API 是什么以及卖家为什么需要使用 API，请 [参阅相关指南](https://seller.wildberries.ru/instructions/ch/ch/material/what-is-wb-api-and-how-to-work-with-it-china)。

## 什么是 OAuth 2.0

OAuth 2.0 是一种现代且安全的授权协议，它允许第三方服务仅访问您店铺中所需的数据。接入过程中无需提供登录名和密码，也无需手动创建令牌，只需在界面中确认授权即可。

通过 OAuth 2.0 连接或断开服务的操作仅限个人后台所有者进行。

## 何时可以使用 OAuth 2.0

这种接入方式适用于以下情况：

- 您想使用的服务支持 OAuth 2.0。 [在目录中](https://seller.wildberries.cn/auth-services)，这类服务会标注“支持 OAuth 2.0”或“简化接入”；
- 您希望快速、安全地接入经过验证的第三方服务，而无需手动设置令牌。

## 通过OAuth 2.0 接入的工作原理

通过 OAuth 2.0 接入的流程如下：

- 服务会自动请求仅其工作所需的数据访问权限；
- 您在卖家后台界面中点击确认授权；
- 系统自动生成安全令牌并传递给该服务。

## OAuth 2.0 使用特点

- 您无需像使用令牌时那样选择提供哪些数据访问权限。服务只会请求其正常工作所需的数据。
- 无法部分限制数据访问权限：您要么接受服务的条件，要么拒绝接入。如果服务无法获取所需的全部权限，可能会无法正常工作。
- 集成会保持激活状态，直到您在个人后台中断开服务，或服务自身断开连接，例如您不再使用该服务。

## 使用 OAuth 2.0 的优势

- 简化接入：无需手动创建和传递令牌。
- 安全性高：服务仅能访问其正常工作所需的数据。
- 无需每 180 天手动更新令牌：与令牌不同，访问权限会持续有效，直到您或服务主动断开。
- 集中管理：通过 OAuth 2.0 接入的服务可在个人后台“ [API接口对接](https://seller.wildberries.cn/api-integrations)”中查看和断开。

## 如何通过 OAuth 2.0 接入集成

- 首先确认您在要接入的服务中已有账号。如果还没有账号，请先在该服务中注册。
- 打开 [Wildberries 商业解决方案目录](https://seller.wildberries.cn/auth-services)。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/eb669221-50c5-4d04-a206-e6d2cf9bf8ee.png.webp)

- 找到所需的服务，并在其页面上点击“连接”。
- 确认您已拥有该服务的账号，并仔细查看将被请求访问的数据列表。
- 允许访问所列数据。Wildberries 会自动生成具有所需权限的令牌，并安全地传递给服务。
- 在服务的个人后台中设置其功能（如有必要），确保所有所需功能已启用。如果服务基于订阅，请在服务端完成支付。
- 检查服务是否成功接入。可在个人后台的“ [API 接口对接](https://seller.wildberries.cn/api-integrations) → 已连接的服务”中查看，那里会显示所有通过简化方案接入的活跃集成列表。

已接入的服务不会自动开始工作，可能需要在服务端进行额外设置或激活订阅。

## 如何断开通过 OAuth 2.0 的集成

如果不再需要某项服务：

- 在个人后台设置中打开“API 接口对接 → 已连接的服务”，您将看到所有已连接的第三方服务列表。
- 选择要断开的服务并点击它。
- 在弹出的窗口中点击“断开接入”，该服务将失去对您数据的访问权限。
- 确认断开连接。断开后，服务立即失去对您数据的访问。

请注意，在卖家个人后台断开服务接入并不会取消该服务本身的订阅。如果您不打算继续使用该服务，请务必在服务官网取消订阅。

## 如果通过 OAuth 2.0 集成无法正常工作

- 在个人后台设置中打开“API 接口对接”标签页。
- 确认服务页面上没有错误提示。
- 检查服务是否能够接收和传递数据（如服务提供此功能）。
- 如果第三方服务无法使用，请联系该服务的客服。大部分目录中的服务页面都提供联系方式和接入指南链接。

如果怀疑是 WB API 出现故障，请查阅 [API文档](https://dev.wildberries.cn/) 及，或 [联系 Wildberries客服](https://seller.wildberries.cn/service-desk-v2?tab=all)：在“API”类别下创建咨询请求。
