如何跟踪订单状态

订单状态仅针对已移交至配送的订单显示。要将订单移交至配送，请进入 “供货与订单” → FBS → [配货中](https://seller.wildberries.cn/marketplace-orders-fbs/on-assembly)，点击供货右侧的三个点，选择 “交给配送”。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/0194bcfa-425e-457c-a173-4c82605d94ac.webp)

您可以通过卖家后台或 API 跟踪订单状态。

## 卖家后台

1. 进入 “供货与订单” → FBS → [配送中](https://seller.wildberries.cn/marketplace-orders-fbs/on-delivery)，点击所需的供货。




![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/a9bffc98-c7f5-4046-bd73-e567ce71773b.webp)

2. 在 “状态” 列中即可查看订单状态。状态需要按每个订单号单独查看。




![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/1b0ba15a-ce08-4e6e-8187-094790d03af5.webp)

3. 点击具体状态，可查看状态变更历史记录。




![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/b8f8bd7d-de3a-4f32-b6e0-9005636b28c1.webp)


## API

要通过API跟踪订单状态，您需要接入WB API。具体操作方法请参阅 [指南](https://seller.wildberries.ru/instructions/ch/ch/material/what-is-wb-api-and-how-to-work-with-it-china?categoryId=api-integration&goBackOption=prevRoute)。

也可以通过 [Get Assembly Orders Statuses](https://dev.wildberries.ru/en/openapi/orders-fbs/#tag/FBS-Assembly-Orders/paths/~1api~1v3~1orders~1status/post) 接口跟踪订单状态，通过 [Status History for Cross-Border Orders](https://dev.wildberries.ru/en/openapi/orders-fbs/#tag/FBS-Assembly-Orders/paths/~1api~1v3~1orders~1status~1history/post) 接口查看状态变更历史。

在头程配送阶段有 2 种状态：

- 合作伙伴已接收（卖家已将订单交付给所在国家的配送服务 / accepted\_by\_carrier / dispatched\_to\_delivery\_service）—— 头程合作伙伴已接收订单，用于分拣并转交给国际合作伙伴，后续由其完成订单配送。
- 已发给合作伙伴（正在运往卖家所在国家的配送仓库 / sent\_to\_carrier / on\_way\_to\_delivery\_service）—— 订单已完成分拣，并已交由合作伙伴进行后续配送。
