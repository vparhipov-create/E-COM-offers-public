RETS仓库

在 [WB Plus](https://seller.wildberries.ru/instructions/ch/ch/material/wb-plus-model-in-china?categoryId=about-marketplace-model-fbs-china&goBackOption=prevRoute) 销售模式下，您可以将商品存储在WB Plus合作仓库—东莞RETS仓库中。此举将有助于加快您商品的配送速度，并因此提升其在搜索结果中的排名。

## RETS仓库优势

- 快速配送：至俄罗斯中部地区仅需10天。
- 免费服务包括：
- - 商品在RETS仓库存储180天；
  - 卸货、分拣及上架服务；
  - 贴标及国际快递所需的基础包装；
  - 完整的报关及清关服务全流程。

## 连接RETS仓库

1\. 请联系 RETS 并提交仓库接入申请。联系人, 叶经理 : 18038319391

2\. 申请处理完成后，该仓库将在您的后台可用。请 [创建一个新的卖家仓库](https://seller.wildberries.cn/marketplace-pass/warehouses)，并从列表中选择 50131977-WB Plus Dongguan-7Days-Air-All goods

3\. 登录RETS OMS系统，配置并提供您的WB API令牌及仓库ID。

当您为与 Wildberries 的集成配置 API 时，会创建 API 令牌。您可以在“ [API 集成](https://seller.wildberries.cn/api-integrations)”部分查看该令牌。

要获取令牌，请点击“创建新令牌”→ 输入任意令牌名称并选择“内容 \+ FBS” → 令牌将被创建。

使用它为您的店铺在 OMS RETS 系统中授权。为此，请将其粘贴到“token”字段中。

请注意，在创建 API 令牌时，不需要勾选“测试”和“只读”字段。如果您在创建令牌后没有立即复制，请将其删除并创建新的令牌。

在您使用令牌于 OMS RETS 系统期间，不能在 WB卖家后台的个人账户中删除它。如果您删除令牌，系统将无法获取 Wildberries 的订单、标签和供货数据。

Warehouse id 可在卖家后台的“供货与订单”板块中，“我的仓库与通行证”部分查看。

步骤3.2 OMS系统

登录OMS系统，到【平台账号管理】界面，进入wildberries平台账号授权。

菜单：OMS → 平台管理 → 平台账号管理 选择Wildberries，填写店铺名和token，点击【确认】

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/95c55996-fe3c-40a8-a56f-219ca9c0b418.png.webp)

步骤3.3 平台账号开启拉单

菜单：OMS → 平台管理 → 平台账号管理

【平台账号管理】界面，可查看到授权成功的新店铺账号

点击【开启拉单】，系统开始自动抓取新账号的已支付未发货订单.

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/9fec239b-9fa6-48c6-92f9-cf3aa48bbd61.webp)

如果有授权时间之前的订单要抓取到OMS系统仓库发货，可点击【抓取订单】，可以选择时间段抓取订单。

如果需要抓取指定的订单，可选择时间+指定单号，对指定订单进行拉取

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/ca3113b5-2026-4247-9918-7561ab01fad3.png.webp)

如果没有正常抓取，可能是授权信息错误，可点击【修改】重新授权。

店铺授权异常，如何处理?

一般是token填写错误，例如token前后多填了空格. 处理方式：指定店铺重新授权. 平台账号管理界面，找到订单对应的店铺. 点击【修改】注意：店铺重新授权不要修改店铺名称，填写正确的token后直接点【确认】。

步骤3.4 维护平台SKU关系

OMS系统下载到的平台订单商品明细为平台SKU\*数量，其中平台SKU需要转换为仓库SKU，仓库才能正常发货，平台SKU与仓库SKU的对应关系，需要在OMS系统维护.

菜单：OMS → 平台管理 → 平台SKU关系

3.4.1 手工添加平台SKU关系，

点击【新增】，填写平台SKU，选择账号，维护该账号下 平台SKU实际要发货的OMS SKU和数量（单品一对一发货实际发1个，数量填1）。如果发多品，可点击+，添加OMS SKU2。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/17d9a125-a754-44c0-97ff-ce183e84baff.png.webp)

例如在diy-fun-toys账号下的订单，客户购买1个平台SKU：1123-78，实际仓库需要发的SKU为：1个SKT-1123-8+1个SKT-1123-7，数据维护如下图：

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/6e9438c1-6c7a-40cb-877b-a9d376812b11.png.webp)

3.4.2 批量导入平台SKU关系

点击【导入】，下载系统模板，填写信息后批量上传

- 只绑定平台，未指定店铺，表示该平台下按照对应行的SKU关系发货.
- 绑定平台+指定店铺，表示在该店铺下按照对应行的SKU关系发货.
- 未指定平台+未指定店铺时，对应行的SKU关系适用于所有订单.

系统优先识别指定店铺的SKU关系；无指定店铺SKU关系，有指定平台时，使用指定平台对应的SKU关系发货；未指定店铺且未指定平台时，作为通用SKU关系发货。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/b6f53b42-e4fa-4bde-8540-6953194bcca4.png.webp)

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/67013906-59fb-492c-82d8-3ed71eefc7a6.png.webp)

步骤3.5【待处理】的平台订单，转系统订单并审核

系统自动下载的平台订单，需要在平台订单管理界面查看后处理，才能转为仓库订单发货

菜单：OMS → 平台管理 → 平台订单管理

选择要发货的平台wildberries，【待处理】状态下，勾选需要仓库发货的订单.

- 点击【转系统订单并审核】，该订单将生成一个对应的系统订单，并自动审核该订单，审核结果在【出库订单】→【订单列表】查看，审核成功的订单可在【已审核】状态下查看，审核失败的订单可在其他状态查看. 已处理状态下，也可以看到对应的系统订单状态

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/1e3886d4-43f8-40e3-ba3d-b31b166fbc4d.png.webp)

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/008e8026-3323-4f91-ad8c-aa8e6c9405e3.png.webp)

- 点击【转系统订单待审核】，该订单将生成一个对应的待审核系统订单，可在【出库订单】→【订单列表】→【待审核】状态查看，

注意：待审核状态的订单，需要审核成功，才会被提交至仓库操作发货.

- 暂时无需发货的订单，可勾选订单，点击【冻结】，平台订单将转到【冻结】状态，该状态订单也可转系统订单继续处理

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/c1773aaa-faf9-49d8-b4f0-23a41b5b379a.png.webp)

- 订单信息不使用/不再发货可点击【作废】。注意，点作废只针对本次拉取的订单内容，不会对应作废平台上的订单。OMS系统作废的平台订单，会显示在OMS【平台订单黑名单】界面，如果需要恢复发货，可以将平台订单从黑名单界面作废.
- 【重新匹配SKU】：适用于平台订单已抓取到OMS系统之后，又修改了平台SKU关系，或者平台抓取订单后才维护平台SKU关系的情况。点击可再次为平台订单匹配海外仓SKU。
- 【映射同名SKU】：该功能是系统快速创建平台SKU关系。适用于平台SKU=客户SKU或仓库SKU。 例如A客户的平台SKU为A1，系统SKU=A-A1，映射同名SKU时，系统自动创建平台sku 的A1=系统A-A1

- 如果转系统订单时提示\[未匹配到SKU对应关系:XXXXXX\]，表示所选择的平台订单SKU，未维护对应的系统发货SKU。 可点击【新增SKU映射】或者到【平台SKU关系】界面，补充维护该平台SKU对应的系统SKU关系

步骤3.6【已处理】的平台订单，回传单号，创建WB发挥批次（适用于wildberries FBS订单）

注意：这一步，WB订单要单个店铺操作，无法对不同店铺的订单创建一个发货批次。

操作【回传单号】后，要及时关注回传结果。回传异常的订单，可以在【已处理】订单下看到异常提示。

## 常见问题

如何创建供货单？

供货只需在RETS OMS系统中创建，Wildberries卖家后台无需进行额外操作。

在哪里可以追踪批次库存？

批次库存数据将仅在RETS OMS系统中显示。

费率标准是怎样的？

费率标准详见 [要约](https://seller.wildberries.ru/confirm-offer-condition/product/view) 第13.1.11条。
