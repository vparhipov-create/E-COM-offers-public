如何通过令牌连接API

通过令牌集成是将第三方服务或自有系统连接到卖家店铺的一种方式。令牌是一个数字密钥，用于与您在平台上的店铺数据进行集成。

关于 API 的概念及其对卖家的作用，请 [参阅相关操作指南](https://seller.wildberries.ru/instructions/ch/ch/material/what-is-wb-api-and-how-to-work-with-it-china)。

## 什么时候需要使用令牌集成

此连接方式适用于以下情况：

- 您使用自有程序或开发系统；
- 您想连接不支持 OAuth 2.0 的第三方服务。

如果服务支持 OAuth 2.0，建议使用 OAuth 2.0 进行集成，因为该方式更方便、更安全。关于此连接方法的详细说明， [请参阅相关文章](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-connect-to-api-via-oauth-2-china)。

如果您计划实现自有集成，首先应了解 [WB API 开发者网站](https://dev.wildberries.cn/)，以获取可用方法和操作示例的信息。

## 如何通过令牌集成

- 卖家在个人账户中生成令牌并设置访问权限：选择该令牌可以访问哪些具体的数据类别。
- 卖家将令牌提供给开发人员，或自行在要连接的服务设置中输入令牌。

一个令牌的有效期为 180 天。到期后，需要重新生成并在集成中更新，否则通过该令牌连接的第三方服务或自有信息系统将失去对 WB Partners店铺数据的访问权限。

我们建议为每个新集成创建单独的令牌，这样更便于管理访问权限，并在需要时进行关闭。

只有个人账户的所有者可以创建和删除令牌。更换账户所有者后，所有令牌将无法正常工作，需要重新创建。

## 如何选择令牌类型

您可以使用4种令牌类型，每种令牌都用于特定的任务。

### 个人令牌

具有扩展功能的专属令牌，用于将卖家数据的访问权限仅授予您自己的程序——包括部署在自有或租赁基础设施上的企业系统（on-premise）。

扩展功能，是指部分数据类别仅能通过个人令牌获取，而其他类型的令牌则无法访问。例如，用户管理功能仅支持使用个人令牌。

适用于:

- 公司部署在自有或租赁服务器上的自有软件产品或系统,
- 已有的ERP/CRM系统（on-premise），包括部署在公司服务器或用户计算机上的1C本地版本（盒装）。

个人令牌可访问敏感信息，因此不得将其转让给第三方或在云服务中使用。创建令牌时，系统将显示责任提示——您需要接受该提示才能继续操作。

令牌由您自行设置。如果不确定要填写哪些参数，请咨询负责所连接系统的开发人员或 IT 专家。

若您在自有或租赁的服务器上使用自有程序或本地系统（也称为“盒装”或on-premise），请选择个人令牌。

### 服务令牌

用于连接Wildberries官方 [商业解决方案目录](https://seller.wildberries.cn/auth-services) 中特定云服务的专用令牌。

特点：

- 与特定服务绑定，且仅能用于该服务,
- 创建令牌时，您从目录中选择服务，此后所有必要设置，包括数据类别和访问级别都将自动填写。您只需确认创建令牌并将其提供给服务即可。

如果您想连接解决方案目录中的现成云服务，请选择使用服务令牌。

### 基础令牌

基础令牌是一种辅助令牌，将来可用于访问卖家有限的数据集。当服务令牌或个人令牌不适用时，可使用基础令牌。

适用场景：

- 在正式上线前，用真实数据测试集成；
- 其他无法使用服务令牌或个人令牌的情况

创建基础令牌时，您可以自行选择数据类别和访问权限等级——只读或读写。

在测试集成或其他类型令牌不适用的情况下，请选择使用基础令牌。

### 测试令牌

这是一个专用于在 [WB API 沙箱环境](https://dev.wildberries.cn/) 中安全测试和调试集成的特殊令牌。

适用场景：

- 开发和调试集成时，不会影响真实数据；
- 学习 API 功能并进行方法实验；
- 在正式环境上线前测试新功能。

测试令牌仅在沙箱中有效，可访问生成的测试数据，真实商店数据不可用。

在开发和测试集成时，请选择使用测试令牌。

关于如何创建、删除或更新令牌，请参阅 [单独的操作指南](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-create-update-or-delete-a-wb-api-token-ch)。

## 使用令牌的安全规则

令牌类似于您个人账户的密码，但这个密码不是人使用，而是由程序使用。

在使用令牌时，为了保障数据安全，需要遵守以下重要规则：

- 妥善保存令牌：像保存密码一样保存令牌。建议使用密码管理器或安全存储，而不要将其记录在文本文件或聊天工具中。
- 限制令牌访问权限：只有负责 API 集成的员工才应有访问令牌的权限。
- 记录令牌失效日期：可在密码管理器或其他安全位置记录，以便及时更新令牌。如有需要，也可记录令牌创建日期。
- 管理所有创建的令牌：记录每个令牌的用途和对应服务，以便在需要时快速禁用。

通过提供令牌，您会向第三方开放对您店铺和账户信息的访问权限，这些信息可能包含您的个人数据。因此，在向合作伙伴、集成商或开发人员提供访问权限前：

- 确认信任该接收方；
- 必要时控制并限制访问权限。

如果与第三方服务或开发人员的合作结束，应立即删除令牌。

## 如果通过令牌集成无法正常工作怎么办

如果集成出现问题：

- 检查令牌是否正确且未过期。如果令牌已过期（超过 180 天），请创建新的令牌并在服务中更新。如果您在多个集成中使用同一个令牌，重新生成后需在所有使用该令牌的地方进行替换。
- 确认服务能从 WB Partners店铺获取数据并返回。方法如下：

如果集成仅用于从平台获取数据，在卖家后台修改相关数据后，检查连接的集成服务是否接收到这些变化；

如果集成将数据传回 WB Partners店铺，在您的系统中修改相关数据后，检查平台是否接收到这些变化。只需修改确实需要同步到后台的数据。例如，如果服务用于处理评论，请在服务中准备评论回复并发布，然后检查该回复是否显示在WB Partners后台

- 如果自定义集成出现错误，请联系负责该集成开发的开发人员。
