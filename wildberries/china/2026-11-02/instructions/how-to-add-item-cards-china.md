如何创建商品

要创建商品详情页，请进入 [“商品与价格”板块 → “商品详情页”](https://seller.wildberries.ru/new-goods/)，然后点击“添加”。选择“单个商品”。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/a38f36d3-9074-4b8e-b01a-56dbd9d4bd7c.png.webp)

关于如何一次性创建多个商品详情页，请参阅 [单独的指南。](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-add-item-cards-in-bulk-china?categoryId=how-to-add-cards-in-bulk&goBackOption=prevRoute)

## 如何正确填写商品详情页

正确填写的商品详情页是良好销售的关键。为了让商品详情页获得高评分，在商品目录中获得更好的排名，并在搜索和筛选中对买家可见，请遵循以下建议。

重要提示！

某些商品类目有填写商品详情页字段的特殊规则。

这些针对特定类目的规则已汇总在 [“商品类目”文章](https://seller.wildberries.ru/instructions/ch/ch/material/product-cetegories-china?categoryId=about-item-card&goBackOption=prevRoute) 中。请务必阅读，以便正确填写商品详情页，避免罚款和屏蔽。

如果您使用俄语界面，则需直接使用俄语填写文本。俄语译文应保证专业度。如果文本中存在大量错误或描述不清，买家将难以通过搜索找到您的商品，同时商品详情页的评级也会下降。

如果您不懂俄语并使用中文界面，则需用中文填写所有字段。保存商品详情页后，系统会自动将文本翻译成俄语。

### 商品名称

显示在商品详情页标题中的商品名称。最大长度为 60 个字符。

商品名称在商品目录中可能无法完整显示，建议在选择词序时考虑这一因素。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/4993bd07-656b-4d7a-b42d-d7ec2e036585.png.webp)

名称应简短准确地回答“商品详情页图片中展示的是什么？”这一问题。不要有多余内容，只保留核心信息。所有细节可以在商品属性和描述中添加。

避免：

- 同义词和词语重复
- 不描述商品或描述不准确的词语
- 多余细节，例如成分或使用方法
- 用逗号或斜杠列举多个名称
- 标注性别和年龄
- 品牌名称
- 标注季节
- 主观评价，如“最佳”、“超级”、“爆款”
- 全大写字母书写的词语
- 仅使用拉丁字母、不含西里尔字母的词语
- 特殊符号：/ \\* \- \+ @ № % & $ ! = ( ) { } \[ \]
- 电话号码、邮箱、链接、即时通讯账号
- 表情符号
- 不雅词汇

### 类目

当您输入商品名称或添加商品图片后，系统会自动推荐最合适的类目——您只需选择即可。

如果尚未填写名称，您可以自行查找类目：浏览列表或使用搜索框搜索。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/c3d1a6aa-a39e-4534-a336-a7dd703b30b6.png.webp)

重要提示！

某些商品类目有填写商品详情页字段的特殊规则。

这些针对特定类目的规则已汇总在 [“商品类目”文章](https://seller.wildberries.ru/instructions/ch/ch/material/product-cetegories-china?categoryId=about-item-card&goBackOption=prevRoute) 中。请务必阅读，以便正确填写商品详情页，避免罚款和屏蔽。

### 卖家商品编号

您自己为方便搜索商品详情页而设定的唯一商品标识符。可随时修改。允许任何字符，但不超过 72 个字符。

注意不要将商品编号与条形码混淆：

- 商品编号是您的内部工具，无需印在商品上，可以是任意内容，我们不做任何查验或审核
- 条形码是仓库验收时扫描的代码，用于识别商品，必须印在包装上

使用星号图标可以随机生成商品编号：

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/1d4cb9b9-46cb-4f94-a867-eaa8a05dffad.png.webp)

### 品牌

品牌是印在包装或商品上的厂牌或商标。请从建议列表中选择品牌。

品牌必须与商品类目相符——例如，如果您选择了“服装”类目，建议列表中只会出现服装品牌。

品牌字段中请勿填写您卖家公司的名称。品牌是指商品本身的商标。品牌名称不得以符号开头，也不得与商品类目名称相同。品牌名称中禁止使用斜杠（/）和重复词语。

如果不选择品牌，该字段将自动显示“无品牌”。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/4bcdfdee-77d6-4ae2-ac29-50f980785b27.png.webp)

如果列表中找不到您的品牌，您可以添加它——点击“添加品牌”进入品牌账户并开始创建。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/05975eab-67d7-4bb0-b518-45b342f1b4fd.png.webp)

更多关于创建品牌的信息，请参阅 [指南“如何在 Wildberries 上添加品牌”](https://seller.wildberries.ru/instructions/ch/ch/material/how-to-create-brand-for-china?categoryId=about-item-card)。

### 颜色

当您开始输入颜色时，系统会推荐合适的颜色选项。您最多可选择 5 个值。

建议只选一个主色——最贴切的那个。买家筛选器中的颜色是按基础色分组的：例如有“绿色”，但没有“草绿色”或“浅绿色”。因此选择“绿色”就足够了。

如果商品只有一个但包含多种颜色（例如一包多色袜子或带有双色印花的手机壳），请在同一个商品编号的商品详情页中列出所有颜色。也可以为一个商品编号指定同一颜色的多个色调。

如果不同颜色代表不同的商品（例如同款不同色的 T 恤），请为每种颜色创建单独的变体和商品编号。

要创建同款商品的不同颜色变体，请使用左侧的“变体”选项。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/082ac2cf-c3b1-4c71-9219-acb7efaaece6.png.webp)

### HS 编码

用于确定商品类目、海关税费金额及贴标要求的分类编码。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/9671764e-ce58-4473-88d7-5417edd5c5f3.png.webp)

在“HS 编码”字段中只能从下拉列表中选择值。请仔细选择代码，因为这会影响验收单中是否出现标记码，以及在创建供货时是否会出现多余的标记商品标记。

请务必根据 [最新规则](https://eec.eaeunion.org/comission/department/catr/ett/) 核对您选择的 HS 编码是否正确。

### 描述

描述应简洁、真实、信息丰富，并与商品相符。

描述中的字符数取决于父级类目。当您指定商品类目后，该类目允许的最大字符数会显示在“描述”板块的右侧。

不同类目商品描述的最大字符数如下：

5000字符：健康、药品

4000字符：家居、保险

3000字符：汽车电子、轿车、家具、食品、运动营养与化妆品、智能家居与安全、窗帘及配件、珠宝饰品

1000字符：酒类产品、数字内容

2000字符：其他所有类目

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/cacfa322-26ee-47a8-81db-4bda1e7cb357.png.webp)

如何填写商品详情页的描述

- 简要介绍商品的特点、优势和使用场景。

在单次创建商品详情页时，有一个便捷功能：您填写描述后，系统会根据文本自动提取属性。

- 描述中无需列举所有属性——属性有单独的字段。

填写的属性直接影响商品展示的频率和受众。

如果属性字段为空，商品详情页的排名会大幅下降，更难出现在搜索结果中。因此，凡是能单独填写的内容（如尺码、颜色、成分、材质等），都请在专门的属性字段中填写。

描述中不要包含：

- 网站搜索会自动收录您的文本内容，并据此形成搜索关键词。
- 任何域名：.ru、.net、.com、.io 等，以及商品编号（包括自己和其他卖家的）
- 特殊符号，例如：/ \\* \- \+ @ № % & $ ! = ( ) { } \[ \]
- 颜色和商品变体的列举——只保留与当前商品详情页具体商品相关的内容
- 与您的商品无关的品牌
- 不雅词汇
- 过多提及尺码
- 所有为搜索结果所需的词语都应添加到商品描述中，不加特殊符号，使用空格分隔。

如何填写属性：通用规则

- 属性必须与商品完全一致。如果值相互矛盾，商品详情页将无法进入商品目录的正确板块——买家在按筛选器搜索时无法看到它。

例如，如果晚礼服的“用途”字段填写了“运动”，它仍然不会出现在运动服装板块。

- 最好填写所有重要属性——这有助于更精准地向目标受众展示商品。建议从系统自动建议的值中选择。
- 如果需要填写多个值（例如颜色或成分），请分别填写。不要在一个字段中用逗号隔开填写——系统无法识别，商品将无法进入筛选器。

例如，如果在“成分”字段中写了“棉”，商品详情页会进入筛选器。如果在同一字段中写了“棉纸木”，系统无法确定准确值，商品详情页将无法进入筛选器。

### 条形码

这是特定商品变体（特定颜色和尺码）的标识符。条形码可印在商品本身或其独立包装上。

条形码在商品验收和发货时会被扫描。因此，务必确保：

- 条形码已印在商品或包装上
- 条形码与商品详情页中填写的内容完全一致

如果条形码不匹配或缺失，商品将无法被接收。

最大长度为 30 个字符。可包含英文字母、数字和符号 / \* - + @ № % & $ ! = ( ) { } \[ \]，禁止在条形码中使用西里尔字母。

可以自动生成条形码——点击“生成条形码”即可。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/fb4ae8c1-cf20-425e-a28e-3318745ff2b3.png.webp)

### 包装尺寸

正确填写商品含包装的尺寸和重量至关重要——物流和仓储费用将根据这些参数计算。建议向上取整。

![image.png](https://static-basket-02.wbbasket.ru/vol20/article-static/7006b936-f427-404f-aedb-6e2a684d4555.png.webp)

请只填写整数。数值不能为零，且不得超过 700 厘米。

如果填写的尺寸偏大，仓储和物流费用可能更高。如果填写的尺寸小于实际尺寸，将根据卖家 [要约第 13.3 条](https://seller.wildberries.ru/confirm-offer-condition/product/view) 处以罚款。

我们会将您在商品详情页中填写的尺寸与类目平均值进行对比。如果发现差异，会显示通知。这有助于您及时发现并修正可能的错误。
