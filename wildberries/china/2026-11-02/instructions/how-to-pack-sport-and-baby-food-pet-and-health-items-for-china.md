如何正确包装食品、运动营养、婴儿食品、宠物用品及健康产品

## 限制说明

请注意，此类商品仅可在俄罗斯境内仓储的ОВХ 模式下销售。

## 含液体商品的包装要求

请提前做好应对变化的准备，确保您的货物完好无损、外观良好地送达买家手中。

| 玻璃包装：<br>如：糖浆、蜂蜜、食用色素、饮用水、果酱、酱料等<br>- 容量 ≤250 毫升 | 使用2 层气泡膜包裹，外层为厚度为 70–100 微米的密封袋，需贴合商品形状封口。 |
| --- | --- |
| - 容量 ＞250 毫升 | 使用气泡膜包裹，外层为厚度为 70–100 微米的密封袋，贴合商品形状封口；<br>再放入贴合商品形状的纸箱，并用胶带密封 |
| 成组包装的商品，如：饮用水、果汁、能量饮料等<br>- 玻璃瓶装 | 每件商品需用气泡膜 \+ 厚度为 70–100 微米的密封袋包装，贴合商品形状；<br>整组外层用纸箱包装，并用胶带密封。 |
| - 塑料瓶、金属罐或利乐包，容量 ≤500 毫升 | 整组使用气泡膜 \+ 厚度为 70–100 微米的密封袋，贴合商品形状封口。 |
| - 塑料瓶、金属罐或利乐包，容量 ＞500 毫升 | 整组使用厚度为 70–100 微米的密封袋，贴合商品形状封口+ 纸箱包装，胶带密封 |
| - 软袋包装 | 只接收整组形式入库；<br>包装方式为：厚度为 70–100 微米的密封袋，贴合商品形状封口 |
| 宠物食品、罐头及其他相关商品：<br>- 金属罐、塑料包装、出厂纸箱包装、吸嘴袋或原厂包装袋 | 包装方式1：<br>使用气泡膜 \+ 厚度为 70–100 微米的密封袋，贴合商品形状封口<br>包装方式2：<br>使用纸箱包装 \+ 胶带密封 |
| 容量大于3 升的塑料桶装商品 | 使用厚度为 70–100 微米的密封袋，贴合商品形状封口 |
| 铝罐包装商品：鼻腔喷雾、植物油、喷雾奶油等 | 包装方式1：使用气泡膜 + 厚度为 70–100 微米的密封袋，贴合商品形状封口<br>包装方式2：使用纸箱包装 + 胶带密封 |

## 干货及散装商品的包装要求

请提前做好应对变化的准备，确保您的货物完好无损、外观良好地送达买家手中。

| 干货、保健品、能量棒、茶叶、香料及其他干散食品：<br>- 塑料包装、出厂纸箱或礼盒包装 | 包装方式1：使用气泡膜 + 厚度为 70–100 微米的密封袋，贴合商品形状封口<br>包装方式2：使用纸箱 + 胶带封口<br>截至 2025年9月1日，塑料瓶装的保健品可仅用厚度为 70–100 微米的密封袋进行贴合封装，无需额外包装。 |
| --- | --- |
| 面粉、谷物、填充料、宠物零食、宠物粮等商品：<br>- 纸袋包装 | 使用厚度为 70–100 微米的密封袋，贴合商品形状封口 + 纸箱包装，胶带密封 |
| - 自立袋或原厂密封袋包装 | 使用厚度为 70–100 微米的密封袋，贴合商品形状封口； |
| - 6 公斤及以上的大袋装商品 | 仅允许以单品托盘形式发货。托盘必须用纸板将三面封闭。留一面敞开，须为窄边（80 厘米）；托盘上的每个商品单元的包装要求取决于其原厂包装形式（参考上表） |

## 易碎/易损食品及其他食品类商品的包装要求

请提前做好应对变化的准备，确保您的货物完好无损、外观良好地送达买家手中。

| 软包装薯片、袋装巧克力糖果、造型巧克力、面巢、千层面、细面、薄脆饼、姜饼、硬面包圈、造型饼干、威化饼等。<br>- 纸质托盘式包装，带开放式展示窗 | 包装方式1：用三层瓦楞纸板将展示窗完全覆盖，再用热收缩膜或厚度为 70–100 微米的密封袋封<br>包装方式2：用厚度为 70–100 微米的密封袋贴合封装 + 纸箱包装并用胶带密封 |
| --- | --- |
| - 袋装或软质纸盒包装商品 | 使用厚度为 70–100 微米的密封袋贴合封装 + 纸箱包装，胶带密封 |
| 其他食品类、运动营养、宠物用品及健康类商品 | 统一使用厚度为 70–100 微米的密封袋，贴合商品形状封口 |

## 婴儿食品的包装要求

请提前做好应对变化的准备，确保您的货物完好无损、外观良好地送达买家手中。

| 饮料、果汁、果浆饮料、酸果汤、果泥等：<br>- 玻璃容器包装 | 使用双层气泡膜包裹，外层为厚度为 70–100 微米的密封袋，贴合商品形状封口 |
| --- | --- |
| - 纸盒包装、乐利包、果吸袋 | 使用双层气泡膜 \+ 厚度为 70–100 微米的密封袋（贴合商品形状封口）+ 纸箱包装，胶带密封 |
| 婴儿饮用水（整组包装） | 使用气泡膜 \+ 厚度为 70–100 微米的密封袋，贴合商品形状封口 + 整组装入纸箱 |
| 婴儿奶粉、米糊、茶、饼干、薄脆饼干、零食：<br>- 铁罐、纸盒、利乐包、易撕包包装 | 包装方式1：使用坚固的额外纸箱<br>包装方式2：使用双层气泡膜 + 额外纸箱包装，胶带封口 |
| - 自立袋、果吸袋、袋装 | 使用厚度为 70–100 微米的密封袋，贴合商品形状封口 |
