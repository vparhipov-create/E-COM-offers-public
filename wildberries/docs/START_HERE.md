# Как пользоваться комплектом Wildberries

Материалы в этом публичном репозитории доступны без приглашения и регистрации.

Вставьте общую ссылку на репозиторий в свой ИИ и попросите выполнить [инструкцию подключения](../../AI_START_HERE.md). Помощник с доступными инструментами сам получает файлы, изучает их по этапам и обновляет базу перед ответами.

Для WB он должен начать с навигатора и [правил ответа](ASSISTANT_RULES.md), затем прочитать исходные оферты и приложения. Доступные [девять PDF](../upload/2026-11-02/Для_загрузки) — удобный комплект, который ИИ также может получить самостоятельно. Для WB Global используется [отдельный раздел](../global/2026-11-02/README.md); его страновой охват указан в отчёте.

## Обновление октябрьского комплекта

В комплекте от 02.11.2026 изменён только навигатор: он содержит пять страниц. Остальные восемь PDF совпадают с октябрьскими побайтово. Для последующих выпусков сверяйте состав замены с журналом.

## Как задать вопрос

Укажите дату события, модель продаж, товар и обстоятельства. В ответе нужны номер оферты, пункт, страница исходного PDF и дата действия положения. Страница сборника может отличаться; используйте оглавление и карту страниц.

Для отдельного документа откройте [реестр источников](SOURCES.md). №78 не подтверждена, период №72 требует уточнения; [полные ограничения](COVERAGE.md).
