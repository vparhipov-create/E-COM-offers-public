# Формирование УПД «ДОП» на товары с обязательной маркировкой для поставок типа «Короб»

Обновлено 19.11.2026

Формирование УПД «ДОП» на товары с обязательной маркировкой для поставок типа «Короб»

Эта инструкция — про формирование УПД «ДОП» для поставок типа «Короб». Про формирование УПД «ДОП» для товаров с агрегированными КИЗ, которые отгружаются поставками типа «Монопаллета», есть отдельная инструкция: [«Передача кодов маркировки при отгрузке поставок типа «Монопаллета»](https://seller.wildberries.ru/instructions/ru/ru/material/transfering-labeling-codes-at-monopallet-shipment).

Подробнее о КИЗ и маркировке читайте [в инструкции «Как продавать товары с КИЗ»](https://seller.wildberries.ru/instructions/ru/ru/material/how-to-sell-cim-labeled-items)

Когда продавец реализует [товары с обязательной маркировкой](https://xn--80ajghhoc2aj1c8b.xn--p1ai/business/) по модели «Склад WB» (FBW), Wildberries самостоятельно выводит и, при необходимости, возвращает в оборот их КИЗ. Для этого продавцу нужно передать коды маркировки через универсальный передаточный документ — УПД «ДОП», или УПД по маркировке.

Если вы продаёте товары с КИЗ по модели «Маркетплейс» (FBS), передавать УПД «ДОП» Wildberries не нужно. Вместо этого добавьте КИЗ товара в сборочном задании по алгоритму из пункта [«КИЗ»](https://seller.wildberries.ru/instructions/ru/ru/material/items-labeling-in-fbs#%D0%BA%D0%B8%D0%B7). Вывести код из оборота тоже нужно самостоятельно через [сервис «Честный знак»](https://xn--80ajghhoc2aj1c8b.xn--p1ai/)

## Как работать с УПД «ДОП»

### 1\. Ознакомьтесь с актом приёмки

УПД «ДОП» выставляется к акту приёмки, если в поставке были товары с КИЗ

Перейдите в раздел [Поставки](https://seller.wildberries.ru/supplies-management/all-supplies), выберите принятую поставку типа «Короб» и кликните по ней, чтобы открыть детализацию.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/1f3bf983-9f64-43f7-b2d3-d8376cae8bd2.png.webp)

В правом верхнем углу нажмите «Скачать документы» и выберите «Акт приёмки».

![](https://static-basket-02.wbbasket.ru/vol20/article-static/1606e7d6-3831-4d84-a94f-f79e09a645bc.png.webp)

На ваше устройство загрузится zip-архив, внутри — акт приёмки в формате .xlsx и файл электронной подписи .sig.

Все документы Wildberries подписываются усиленной квалифицированной электронной подписью, которая подтверждает их подлинность. К каждому документу прикладывается файл электронной подписи в формате .sig — проверить ее корректность можно на сайте Госуслуг

В акте приёмки можно увидеть номер документа, дату выставления и коды маркировки товаров в 6-ом столбце:

![](https://static-basket-02.wbbasket.ru/vol20/article-static/916a59fd-f49a-4fe8-aa13-1da62a773b2c.png.webp)

Сформированные акты приёмки хранятся и в разделе Документы — там их можно найти по фильтрам или номеру.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/80d79c91-1eb8-460a-8512-88061efc7354.png.webp)

### 2\. Скачайте черновик «УПД по маркировке»

В течение суток после того, как вы получите акт приёмки, черновик УПД «ДОП» появится [в разделе Документы](https://seller.wildberries.ru/supplementary-agreements) в профиле на портале. Черновик называется «УПД по маркировке» в формате .xml. Номер «УПД по маркировке» — такой же, как у акта приёмки, к которому выставлен УПД.

![](https://static-basket-02.wbbasket.ru/vol20/article-static/026dc322-2409-4e07-81f0-27f53d3a9c8b.png.webp)

### 3\. Заполните УПД

С 1 апреля 2025 года обмен документами должен происходить в специальном формате, который утверждён приказом ФНС № ЕД-7-26/970@ от 19.12.2023.

Это стандартизированный XML-шаблон, по которому формируются УПД для обмена через ЭДО. Формат устанавливает строгие правила: какие поля и коды обязательны, чтобы системы ФНС и других участников ЭДО могли правильно прочитать и обработать документ

Заполнение данных для отправки УПД происходит [внутри вашей системы ЭДО](https://seller.wildberries.ru/instructions/ru/ru/material/electronic-document-management-with-wb). Все необходимые поля уже есть в интерфейсе, но у разных провайдеров могут отличаться названия и внешний вид этих полей. В этой инструкции приведём примерные названия полей.

| Поле для заполнения | Данные для заполнения |
| --- | --- |
| Наименование основания | Акт приёмки товара |
| Номер основания | Номер полученного акта приёмки товара — только цифры |
| Дата основания | Дата полученного акта приёмки в формате дд.мм.гггг. |

Заполненное основание в XML-файле:

![](https://static-basket-02.wbbasket.ru/vol20/article-static/7efb7ffd-032f-4651-b700-7b6afb101ef5.png.webp)

| Стоимость товаров (работ, услуг), имущественных прав | «0» |
| --- | --- |
| Стоимость с НДС | «0» |
| Стоимость без НДС | «0» |
| Налоговая ставка | «без НДС» |
| Обоснование передачи при формировании документа | «0005» (передача Агенту) |
| Сведения о передаче | Укажите статус «Товары переданы» и дату акта приёмки. Период оказания услуг заполнять не требуется |
| Код маркировки | Укажите в специальной строке:<КИЗ>"код маркировки товара из акта приёмки"</КИЗ> |
| Причина выбытия | Не нужно заполнять |
| Цена (тариф) за единицу измерения | Не нужно заполнять |

### 4\. Отправьте УПД

После заполнения отправьте XML-файл через вашего оператора ЭДО. Если вы не подключены к [ЭДО Wildberries](https://seller.wildberries.ru/instructions/ru/ru/material/electronic-document-management-with-wb), подайте запрос на подключение через операторов ЭДО Диадок или СБИС.

Если вы отправляете УПД «ДОП» через Диадок, чтобы данные передавались в ГИС МТ автоматически, нужно [подключить сервис передачи данных](https://www.diadoc.ru/articles/25672-kak_podkluchitsya_k_chestnomu_znaku).

Оптимальный срок передачи УПД — 3 рабочих дня с даты размещения акта приёмки на портале. Если вы не укладываетесь в этот срок, мы всё равно будем ждать от вас отправку документа, но не дольше 3 месяцев с даты формирования акта

Отправлять УПД нужно только по идентификаторам операторов ЭДО.

| Оператор ЭДО | Идентификатор |
| --- | --- |
| Из роуминга или Диадок | 2BM-9714053621-771401001-202407220901086561013 |
| СБИС | 2BEbf200150d4d042b99cdc5391e0601592 |
| Корус | 2BK-9714053621-9258995 |
| Калуга Астрал | 2AE9B79CB25-C314-4686-8BB5-D31433889A64 |

Если вы не используете идентификаторы, мы не сможем подписать документ

### ЭДО Лайт

Пользователям ЭДО Лайт доступен автоматически сформированный CSV-файл для передачи УПД. Его можно скачать в детализации поставки в разделе [Поставки](https://seller.wildberries.ru/supplies-management/all-supplies).

Документ полностью готов к использованию после загрузки с портала. Пожалуйста, убедитесь, что вы скачали и открываете файл именно в формате .csv

Затем этот файл можно использовать для создания УПД в личном кабинете ЭДО Лайт — загрузите его в поле «Сведения о маркировке». Подробнее о том, как работать с CSV-файлами, читайте в базе знаний вашего оператора.

Wildberries не принимает документы, отправленные напрямую в ЭДО Лайт. Если вы отправляете УПД «ДОП» из ЭДО Лайт, настройте роуминг для передачи в Диадок. Инструкция по настройке роуминга есть на сайте « [Честный Знак](https://markirovka.ru/community/transfer-EDI/nastroyka-rouminga-mezhdu-kommercheskim-edo-i-edo-layt)».

Если вы самостоятельно создаёте УПД, ориентируйтесь на особенности заполнения, которые указаны в этой инструкции, а также на базу знаний вашего оператора ЭДО.

Wildberries не принимает корректировочные документы (УКД). При отказе в подписи необходимо отправить УПД по маркировке повторно
