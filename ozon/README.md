# Оферты Ozon: документы, тарифы и обзоры изменений

Публичная подборка материалов по Ozon Россия и Ozon Global. Можно читать без приглашения и скачивать для работы с документами.

**Дата публикации подборки: 2 ноября 2026 года. Последняя проверка источников: 28 октября 2026 года.** Это сохранённые версии, а не подтверждение актуальности всех условий на сегодняшний день. Проверки частичные; ограничения указаны в каждом отчёте.

## Состав

В подборке сохранены обзоры изменений, официальные PDF договоров и тарифов, Excel с комиссиями, логистикой и другими приложениями, ссылки на источники и контрольные суммы.

- `REPORT.md` / `REPORT_RU.md` — выводы и ссылки на первоисточники.
- `COVERAGE.md` — что проверено и что осталось непроверенным.
- `EVIDENCE.md` — основания сравнений.
- `source_urls.json` — адреса исходных материалов.
- `manifest.json` — контрольные суммы файлов публичной подборки.

Россия и Global могут иметь разные условия. Дата вступления условия в силу важнее даты публикации файла. Старые проверки сохраняют свои исходные периоды и ограничения. Не суммируйте тарифы разных редакций и схем работы.

Материалы можно загрузить в свой проект ИИ для поиска по документам. При ответах просите указывать файл, пункт, дату действия и различать подтверждённые сведения и пробелы проверки.

## Источники и статус

Подборка не является официальным ресурсом Ozon. Права на исходные документы принадлежат их правообладателям; публикация не изменяет условия их использования. Ссылки на первоисточники сохранены в обзорах и реестрах.

Публичная копия подготовлена отдельно: без истории закрытого репозитория, локальных путей компьютера, учётных данных и служебного скрипта синхронизации. Обновление публичной подборки по рабочему архиву выполняется общей ежедневной задачей; правила — в [политике публикации](../PUBLICATION_POLICY.md). Даты проверки первоисточников сохраняются в каждом отчёте.
