## Обновление

Публичная копия обновляется по четырём закрытым рабочим источникам еженедельной задачей по вторникам в **12:00 по Москве**. Новые материалы проходят проверку перед публикацией; без изменений пустые коммиты не создаются. Изменения накапливаются между выпусками: один недельный выпуск сопровождается одной общей сводкой. Регулярная синхронизация не заменяет проверку первоисточников.

Из индивидуальных соглашений публикуются только обезличенные выводы: без ФИО, реквизитов ЭДО и финансовых показателей конкретной компании. [Правила публикации и обновления](PUBLICATION_POLICY.md) · [Журнал объединения](CHANGELOG.md).

Подборка независимая: это не официальный ресурс маркетплейсов или органов власти. Права на исходные документы принадлежат их правообладателям. Ссылки на первоисточники, даты и ограничения сохранены в материалах.
